# Slalom 平稳换向与真实碰撞课程

## 换向参考

2026-10-17 的回放诊断发现，后脊柱使用绝对曲率映射，过零时解析速度参考翻转。
同状态推理支持它是左前肩与左后髋目标突跳的直接触发输入。

二阶段在绝对曲率小于 2 时使用圆滑幅值，令 `r=abs(kappa)/2`：

`m = 2 × (3 + 6r² − r⁴) / 8`

区间外仍为绝对曲率。该映射在零点和两端具有连续的一阶、二阶导数，斜率绝对值不超过一。
后脊柱位置和速度均从此映射生成，不单独过滤或删除速度观测。
零曲率时后脊柱保留约 −1.40 度的小弯曲；曲率十五、二十的形态及一阶段参考不变。

参考修复保持动作、观测维度兼容，但旧策略的闭环改善仍需实际评估。
