# Slalom 平稳换向与真实碰撞课程

## 换向参考

2026-10-17 的回放诊断发现，后脊柱使用绝对曲率映射，过零时解析速度参考翻转。
同状态推理支持它是左前肩与左后髋目标突跳的直接触发输入。

二阶段在绝对曲率小于 2 时使用圆滑幅值，令 `r=abs(kappa)/2`：

`m = 2 × (3 + 6r² − r⁴) / 8`

区间外仍为绝对曲率。该映射在零点和两端具有连续的一阶、二阶导数，斜率绝对值不超过一。
后脊柱位置和速度均从此映射生成，不单独过滤或删除速度观测。
零曲率时后脊柱保留约 −1.40 度的小弯曲；曲率十五、二十的形态及一阶段参考不变。

参考修复保持动作、观测维度兼容，但旧策略的闭环改善仍需实际评估。

## 绕杆速度

二阶段按本回合峰值曲率生成恒定前进速度，不随瞬时曲率过零而恢复直行速度。
基础速度和步频的含义不变；基础速度 0.1、2 Hz、峰值十五时全程为 0.05125 m/s。
接近段、周期时间表、世界系路径速度和命令均读取同一规则。
一阶段仍按固定转圈曲率使用原速度曲线，PPO 与策略频率保持 Hole 对齐。

## 无碰撞训练与真实碰撞考核

最新方案不在某一轮强制把训练切换为有碰撞：训练杆始终不产生接触响应，独立考核杆开启实际碰撞。
两个环境使用同一机器人、mocap 杆几何、参考与控制频率。考核采用冻结的确定性策略，
归一化统计不更新；动作、回报和终止信息不进入 PPO rollout，考核也不增加训练步数。
考核前后恢复 Python、NumPy 和 Torch 随机数状态，避免考核改变训练的采样序列。

| 项目 | 当前值 |
| --- | --- |
| 初始化 | 从零训练，`resume=False` |
| 总预算 | 8000 轮，48 个策略步／轮 |
| 转圈 | 0～3000 轮，单回合 20 秒 |
| 无碰撞绕杆 | 3000 轮后新回合进入，单回合 30 秒 |
| 首次碰撞考核 | 至少 500 轮绕杆预训练后，约 3500 轮 |
| 考核间隔 | 100 轮 |
| 考核环境／样本 | 独立 64 环境，每次共 256 个完整回合 |
| 命令采样 | 沿用训练的高度、基础速度及步频分布，默认 55 mm、0.1、1～2 Hz |
| 课程起点 | 整数峰值曲率 5～10，杆心距约 200.52～400.26 mm |
| 课程终点 | 整数峰值曲率 5～15，杆心距约 134.11～400.26 mm |
| 最难档采样 | 精确 30% 概率；其余 70% 均匀采样较易整数档 |
| 推进条件 | 当前最小杆距连续两批各 256 个碰撞回合通过率至少 60%，每档至少 100 轮 |

每次通过考核只把允许的最大曲率增加一，最大杆距保持固定。已有回合不改变杆位或命令，
新范围从下次回合重置起生效。考核未达标则保持当前范围，训练预算不自动延长。
到达曲率十五只表示最难档已经纳入训练；仍需该档连续两批达标才记录“最终档达标”。

## 实际通过判据

考核的成功不是“未跌倒”或“参考时钟已走过”。监视器逐步检查实际基座、前后躯干中心穿越杆平面的时刻，
要求前三根杆按正确的交替侧别依次通过；前后躯干三维包围盒投影与四个足端均越过杆后才计通过。
第一杆处允许初始前躯干已部分越过杆平面，后躯干和足端仍须完成通过。
整个 30 秒回合未跌倒、侧别正确且完成三根杆，才计成功；接触杆本身不直接判失败。
该判据不等同于全身严格零接触，实际接触响应由考核场景的 MuJoCo/Warp 动力学计算。

每个环境每一轮考核只取第一个完整回合。快速跌倒环境后续自动重置的回合不重复计分，
防止成绩被回合长度偏置。训练环境的无碰撞通过率仅记录诊断，不参与课程推进。

## 保存、回放与训练

检查点的 `infos.slalom_state.spacing_course` 保存档位、驻留起点、上次考核轮数、连续批次及历史。
续训恢复这些状态；显式固定曲率／杆距和回放不自动推进课程。
真实碰撞每批结果作为训练产物写入该运行目录的 `collision_evaluations/`，
TensorBoard 使用 `Curriculum/考核通过率`、`峰值曲率上限`、`最小杆心距米` 等字段。
这些考核率只覆盖当前最小杆距及默认命令分布，不代表跨模型扰动或其他地面条件的成功率。

```powershell
uv run train Mjlab-SQuRo-Slalom --agent.logger wandb --agent.resume False --agent.max-iterations 8000
```

完整训练由用户手动启动。考核会增加实际耗时；终端 PPO 的采样／学习耗时不包含独立考核，
考核耗时有单独字段，因此终端 ETA 不包含这部分开销。当前自动考核入口支持单卡训练。
如果真实碰撞考核长期不通过，课程将停留；后续需要独立评估虚拟净空奖励或接触训练。

## 换向极端姿态与动作裁剪（2026-10-18）

### 现象

6300 轮回放在 +→− 过零点出现持续 0.36～0.45 秒的极端姿态：左后髋目标约 −160°（控制下限 −85.9°）、实际贴下限约 0.36 秒；左前肩／肘力矩在异常窗口内分别饱和 100%／97%（正常行走仅 1.1%／2.0%）；基座抬高约 15 mm；后脊柱实际反向偏离参考（+11.8° 对参考 −24°）；局部朝向误差峰值 37°。−→+ 过零与四腿节奏均正常。

### 判定

- 每个周期复现一次（30 秒内 4 次），是系统策略而非随机抖动；异常窗口奖励 17.0／步、正常 28.6／步，策略相当于用约 2% 的回合回报换这个动作。
- 冻结策略参考变体筛选（内侧幅值缓动、过零冻结幅值、步幅减半、初始相位偏移半个步态周期）全部未能改变异常（贴限位 1.47～1.53 秒、饱和 1.78～1.95 秒），说明异常不是参考参数问题。
- 二阶段速度已按峰值曲率固定（`30af263`，回放 CSV 全程唯一值 0.0652 m/s），过零不加速；异常与速度跳变无关。
- 平台边界的脊柱速度参考单步阶跃约 1.3 rad/s，观测归一化 std 仅 0.19～0.27，输入一步约 5.6～6.5σ；它是目标跳变的放大器，不是异常起点（异常在 |κ|<2 窗口内已开始）。
- 400 轮微调加入腿部饱和惩罚（权重 10）后异常仍在（贴限位 1.46 秒对 1.48 秒），仅后脊柱反向偏离和最长摆动略降；该惩罚单独不足以改变系统策略。

### 方案：动作裁剪

`config/rl_cfg.py` 的 `clip_actions` 由 None 改为 3.0。冻结 6300 策略回放（30 秒、2 Hz）：

| 配置 | 左后髋贴限位 | 最长摆动 | 左后髋目标最小 | 左前肩饱和 | 通过三杆 |
| --- | --- | --- | --- | --- | --- |
| 无裁剪，峰值 13 | 1.48 s | 0.57 s | −168° | 1.78 s | 是 |
| ±3.0，峰值 13 | 0 s | 0.19 s | −57° | 1.84 s | 是 |
| ±2.5，峰值 13 | 0 s | 0.14 s | −49° | 1.83 s | 是 |
| ±2.0，峰值 13 | 0 s | 0.40 s | −40° | 0.66 s | 是 |
| ±3.0，峰值 15 | 0 s | 0.13 s | −57° | 2.21 s | 是 |
| ±2.0，峰值 15 | 0 s | 0.21 s | −40° | 0.58 s | 是 |

裁剪后贴限位消失、摆动时长回到正常量级、三杆通过与曲率十五档均保留；代价是基座最高约 70～73 mm（无裁剪约 67 mm）与冻结策略平均回报下降 13%～17%（策略需在新约束下重训恢复）。

### 保留与未采用

- `leg_saturation` 奖励项保留为诊断用途（`_CURVES` 权重为 0，日志 `Data/腿部饱和占比`），后续若饱和仍不可接受可再调权重。
- 换向参考的静态改造（幅值律、相位）在冻结策略上无效且成本更高；若仍要尝试，应在动作裁剪重训之后单独进行。
- 验收脚本 `verify_slalom_training_setup` 的动作裁剪断言改为 Slalom 自身取值 3.0（与 Hole 的差异是有意保留的）。
