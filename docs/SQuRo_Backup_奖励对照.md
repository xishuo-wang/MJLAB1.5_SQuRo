# 翻正奖励对照与平滑性诊断

## 范围

本工具只评估当前训练环境，不修改奖励、模型、参考时序或 PPO 参数。
直接参考策略由训练环境自己的参考生成器和状态机推进，不运行另一套手调状态机。
旧 checkpoint 在当前配置下重评估，不等价于复现其原训练环境。

## 使用

在项目根目录运行三组基础对照：

```powershell
uv run python -B -m mjlab.scripts.Backup.baseline_trivial_policy --num-envs 16 --seeds 42 43 44 --cases zero random reference
```

增加指定策略的确定性与随机采样对照：

```powershell
uv run python -B -m mjlab.scripts.Backup.baseline_trivial_policy --num-envs 16 --seeds 42 43 44 --cases zero random reference trained sampled --checkpoint logs/rsl_rl/SQuRo_Backup/2026-09-11_16-51-44/model_2999.pt
```

- `--time-scale 3`：固定动作时间缩放。
- `--curriculum-iteration 0`：冻结所有策略的奖励课程轮次，不从 checkpoint 隐式继承。
- `--episodes-per-env 1`：每个种子、每个并行环境接收一个完整回合；可增大。
- `--random-amplitude 1`：随机动作 U(-1,1)，对应目标偏移 ±0.3 rad，并非全动作范围探索。
- `--output-dir logs/backup_evaluation`：默认生成带唯一时间戳的目录和 `evaluation.json`。
- 不启动 W&B、训练或可视化。评估目录必须可写；受限环境可指定其他输出目录。

## 公平性与统计口径

1. 所有策略使用相同环境、种子列表、动作缩放、动作裁剪、奖励与终止条件。
2. 每个并行环境只收首个完整 episode；其结束后自动重置产生的后续数据不参与统计。等慢环境结束后才开始下一轮，避免短回合采样过多。
3. 先累计最后一步，再保存 episode；`terminated | truncated` 均计入完成。
4. 奖励分项从 RewardManager 的逐步加权奖励率获取，再按其配置乘 dt；不对 `Episode_Reward/*` 日志进行逐步累加。
5. 每步校验分项之和与环境返回奖励一致；保存总回报、折扣回报、逐项贡献、每秒回报以及成功/失败分组。
6. 利用 Recorder 的重置前回调保留终止步状态，避免读取到下一回合初态。
7. S1/S2 到达按训练阶段实际推进计数，不用全环境平均日志推算成功率。阶段奖励按动作下发前阶段归属，里程碑入账步可能与切换步相差一个控制步。
8. checkpoint 恢复 actor（含观测归一化），切换 eval 模式，并检查评估前后归一化统计严格不变。
9. 当前 reset 是固定仰面姿态，多种子只覆盖采样差异，不构成初始姿态泛化试验。
10. 不满足完整回合条件就报错，不把未完成样本伪装成完整统计。

## 平滑性诊断字段

- `action_delta_l1_sum` / `action_delta_l2_sum`：已裁剪动作的一阶变化，与现有平滑成本同口径。
- `target_delta_*`：变化量乘 action scale 后的关节目标变化，单位 rad 或 rad²。
- `initial_action_delta_l2_sum`：首步从默认目标跳到支撑位的变化。
- `ongoing_action_delta_l2_sum`：排除首步后的变化。
- `action_second_difference_l2_sum`：二阶动作差分；用于辅助识别抖动，不是频谱分析。
- `policy_mean_delta_l2_sum`：分布均值的变化，与实际采样动作变化对照，区分均值颤抖和探索噪声。
- `policy_std_mean`、四个脊柱的 `policy_std_*`、`policy_entropy`：策略分布指标（裁剪前）。
- `spine_rmse_rad`：四个脊柱关节分别对下发前参考目标的跟踪 RMSE，包含终止步。
- `same_trajectory_return_without_smoothing`：仅从既有轨迹回报中扣除 L1/L2 惩罚，不代表移除惩罚后重新训练。
- `metrics_mean` 内的瞬态项也除以整个回合步数；需要累计量时乘 `steps`，不要把它理解为仅对非零事件求均值。

## 已核实的机制与待验证的调整建议

当前 RSL-RL 的 PPO 返回实际平均熵，通用 logger 将其显示为 `Mean entropy loss`。
优化项为 `-entropy_coef * entropy`。因此日志越来越负确实表示熵下降，但不能据此判断过拟合。
高斯微分熵可为负，而且熵只描述分布宽度，不描述策略均值随时间是否平滑。

现有 L1/L2 对缩放前 action 求差，按关节求和，课程内部系数均为 0.1，外部系数均为 1。
同样的关节目标变化，action scale 从 0.5 改为 0.3 后，L1 增强 5/3 倍、L2 增强 25/9 倍。
其中 L1 会惩罚必需的大幅目标变化，L2 还会显著惩罚启动跳变和快速回收；并不是只惩罚高频颤抖。
采样动作 `a=μ+ε` 时，忽略相关性和裁剪，单关节差分平方期望包含 `Δμ²+σ_t²+σ_{t-1}²`。
因此平滑惩罚既约束动作均值，也直接压制探索噪声，容易与翻正初期的探索需求冲突。

建议按顺序做实验，不同时修改全部变量：

1. 先检查直接参考是否成功，以及成功/失败轨迹的总回报和折扣回报排序；失败活满回合所得正奖励不能忽视。
2. 保留现有组作对照；候选训练组先关闭 L1，仅将 L2 内部系数从 0.1 降到 0.003～0.01。腿、脊柱同倍率，不改变关键扭转关节相对权重。
3. 先保持 entropy_coef=0.01、能耗、参考时序和动作缩放不变，验证弱平滑是否能同时保留 S1/S2 探索和减少颤抖。
4. 若确定性成功率稳定，再渐增 L2；例如从 0.005 增至 0.01，再试 0.03。每档都用同一评估集合检查成功率，下降则回退。数值是待验证起点，不是已证实最优值。
5. 若仅随机采样颤抖、均值策略平滑，可在成功稳定后再单独尝试降低熵系数；若均值本身颤抖，降低熵不能替代平滑约束。
6. 不优先加硬低通滤波，避免引入时延破坏目前较短的回收段。后续可考虑参考残差控制或残差平滑，但属于另一项实现变更。

本次未应用上述训练参数建议；需在公平对照结果基础上选择下一项训练实验。

## 2026-09-12 小规模验收结果

结果文件：`logs/backup_evaluation/20260912_121908_155933/evaluation.json`。
每组 4 个环境、种子 42、λ=3；仅用于功能验收和初步诊断，不是泛化结论。
训练策略来自 `2026-09-11_16-51-44/model_2999.pt`，按当前配置重评估。

| 策略 | 成功 | 回合总回报 | 折扣回报 γ=0.99 | 平均回合时长 |
| --- | --- | --- | --- | --- |
| 零动作 | 0/4 | 145.10 | 15.36 | 10.00 s |
| 随机动作 | 0/4 | 56.11 | 6.36 | 10.00 s |
| 直接参考 | 4/4 | 124.16 | 23.67 | 4.53 s |
| 策略均值 | 0/4 | 15.35 | 1.21 | 10.00 s |
| 策略采样 | 0/4 | 11.33 | 0.65 | 10.00 s |

直接参考在约 2.41 s 到 S1、2.87 s 到 S2。其 L1+L2 合计仅扣约 0.147。
零动作靠速度模仿约 60.51、高度约 47.92、位置模仿约 36.67 积累回报。
成功参考的折扣回报仍高于零动作，因此不能只根据未折扣总回报宣称 PPO 更偏好躺倒。
这组结果也不支持“成功轨迹本身的平滑成本过大”；更应验证搜索成功轨迹之前的探索成本。

旧 checkpoint 的熵为 -14.81，动作标准差均值约 0.258，但四个脊柱标准差分别仅为
0.01214、0.01105、0.01396、0.01114（action 单位）；乘 0.3 后，目标角噪声仅约 0.0033～0.0042 rad。
因此全局平均 std 掩盖了脊柱探索收缩；负熵也不能等同于所有关节都同样收缩。
策略均值的动作差分平方和均值约 34.55，采样动作约 37.37，说明当前环境下的颤抖并非全由采样噪声造成。
此结论仅针对旧 checkpoint 在当前配置的表现，不能直接外推到尚未提供的“无平滑但能成功”checkpoint。

下一轮建议先作弱平滑消融，并从相同初始模型、相同种子开始：

- A：现有 L1=0.1、L2=0.1。
- B：L1=0、L2=0.1，隔离 L1 的作用。
- C：L1=0、L2=0.005，测试减弱 L2 后是否保留翻正探索。
- 以上均指课程内部系数；外部 reward weight 保持 1。其余奖励、熵系数、动作缩放和时序不变。
- 若预算有限，可先比较 A/C，但不能单独归因于 L1 或 L2。
- 若弱平滑下四个脊柱 std 仍过早收缩，再单独测试所有关节统一的 std 下限（如 0.05～0.1 action，需验证），不修改关键扭转关节奖励权重。
