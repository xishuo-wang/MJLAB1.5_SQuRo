# SQuRo_Slalom 手调转弯回放与参考对照

更新日期：2026-10-16。把 `D:\Code\SQuRo-MuJoCo\Loco_Turn\Trun_Cyc_Min.py`（力矩 PD 版原地转弯）
迁移到当前 Slalom 环境，用开环手调步态跑真实仿真，量出它的等效曲率与速度，并与当前 RL 参考对照。

## 迁移映射

脚本 `src/mjlab/scripts/SQuRo_Slalom_Replay.py`，参数逐项取自手调脚本的同名常量。

| 手调常量 | 值 | 迁移后 |
| --- | --- | --- |
| `FREQ` | 1.0 Hz | `HAND_GAIT_FREQ`，同时写入命令第 4 维，保证参考同步 |
| `START_TIME` | 0.5 s | `HAND_START_TIME`，起步前保持模型默认站姿 |
| `SWING_RATIO_L/R` | 0.4 | `HAND_SWING_RATIO` |
| `STRIDE_FL/HL`、`STRIDE_FR/HR` | 0.05 / 0.0 | `HAND_LEGS`，内侧两腿零步幅实现右转 |
| `HEIGHT_*` | 前 0.01 / 后 0.015 | `HAND_LEGS` 摆线抬腿高度 |
| `BODY_HEIGHT_*` | 0.060/0.053/0.058/0.05 | `HAND_LEGS` 支撑相离髋高度 |
| `X_OFFSET_*` | −0.015/0/−0.025/−0.01 | `HAND_LEGS` 足端纵向偏置 |
| `PHASE_LAG` | FL 0 / FR 0.5 / HL 0.5 / HR 0 | `HAND_PHASE_LAG`，与参考表同口径 |
| `SPINE_Yaw/F/Pitch/H` | 0.65 / 0.9 / −0.65 / 0.7 | `HAND_SPINE`，写入 F_spine1/F_body/H_spine1/H_body |

关节顺序不同（手调为腿在前、脊柱在后），脚本按 `mdp/indices.py` 的关节名逐名映射，不依赖编号。

有意保留的差异：

- 控制接口：手调用力矩 PD（kp=2.5、kd=0.001、±0.2 N·m），本环境用关节位置执行器
  （动作缩放 0.3、默认偏置为 `SQuRo_constants.INIT_STATE`），因此迁移保留的是轨迹与姿态设计。
- 控制频率：手调高层 200 Hz，本环境 100 Hz（`decimation=5` × 0.002 s）。
- 逆运动学偏置：手调调用 `inverse_kinematics_old`（0.888/2.648/4.325/1.794），当前任务的
  `mdp/reference.py` 用另一组标定（0.868/2.643/4.35/1.75）。脚本用 `--ik-set legacy|current`
  两组都能跑，默认 `legacy` 保持忠实迁移。
- 颈部：手调保持初始 0，脚本保持当前模型复位值 `(0, −0.3)`，与训练复位一致。
- 命令：固定 `fixed_curvature=−20`、`fixed_gait_freq=1.0`、`fixed_velocity=0.1`、`phase0_only=True`，
  只用于生成对照参考，手调策略不读取命令；奖励与终止项清空，保证 20 秒连续回放不被打断。

## 测试方法

```powershell
uv run python -B -m mjlab.scripts.SQuRo_Slalom_Replay --visualize none --duration 20 --ik-set legacy
uv run python -B -m mjlab.scripts.SQuRo_Slalom_Replay --visualize none --duration 20 --ik-set current
uv run python -B -m mjlab.scripts.SQuRo_Slalom_Replay --visualize video --duration 10
```

1 个环境，20 秒，1 Hz 步频；分析窗口取 2.0～20.0 s，跳过 0.5 s 起步冲击与一个步态周期。
等效曲率由基座水平轨迹的 Kasa 圆拟合给出（符号取偏航角速度方向），另给出运动学估计
`ω / 路径速度`；净前进速度按 `ω × 拟合半径` 计算，与"路径长度速度"分列，后者含每周期往返摆动。

## 结论

1. 手调步态在当前模型与位置执行器下可稳定站立右转：20 秒无跌倒，四足接触力 0.56～0.92 N，
   基座高度稳定在 0.054 m，18 秒绕完一整圈（偏航总变化 −6.34 rad）。
2. 实测等效曲率只有 **−11.6 1/m（R=86.3 mm）**，约为参考标称最大曲率 20（R=50 mm）的 58%。
   手调的内侧腿纵向行程为 0，按参考自身的参数化 `ρ = 1 − |κ|/20` 恰好对应 `|κ|=20` 端点，
   说明"内侧腿停摆"这一设定在开环实现下只能达到 R≈80–86 mm，而不是标称的 50 mm。
3. 速度上，手调每周期净前进 30.4 mm（0.030 m/s），约为参考在 κ=−20 时命令速度 0.015 m/s 的
   2.0 倍；但路径长度速度 0.0535 m/s 中有约 43% 是每周期往返摆动（轨迹上表现为小环），
   不是有效前进。参考在同曲率档的 Phase 0 速度律给出 0.0508 m/s，与路径速度接近、与净前进速度差 1.7 倍。
4. 姿态上，手调脊柱 `(0.65, 0.9, −0.65, 0.7)` 与参考在 κ=−20 的脊柱参考同源，实际角因模型 ±0.6
   限位停在 ≈±0.585，脊柱 RMS 仅 0.035 rad。
5. 最大姿态差异在颈部：手调保持复位 `(0, −0.3)`，参考在 κ=−20 给 `neck_yaw=−0.8`，颈 RMS 0.566 rad。
6. 腿部关节 RMS 0.483 rad，主要来自支撑高度不同（手调前腿离髋 58 mm，参考 52.9 mm）与相位口径不同；
   按最佳相位平移（0.43 周期）对齐后整体 RMS 从 0.423 降到 0.259 rad。
7. 两组 IK 标定给出的半径只差 6.7 mm，说明上述差距来自步态设计本身，不是关节偏置标定。

## 限制与未决

- 手调脚本起步是硬切、没有过渡段，实测 t≈0.6 s 出现 0.42 m/s、4.4 rad/s 的冲击，分析窗口已排除；
  若要当作参考轨迹使用，需要先补过渡段。
- 轨迹不是精确圆（径向残差 4.47 mm，每周期一个小环），等效曲率用整段拟合，未做逐周期估计。
- 基座前向速度均值只有 0.013 m/s，因为机体主要在自转，基座前向与路径切向并不一致；
  与参考比较速度时应以净前进速度为准。
- 足端横向/轴距没有可靠口径：脊柱弯到 0.9 rad 后，单一基座偏航坐标系不足以描述各腿朝向，
  直接用基座系投影会混入脊柱弯角。足端纵向行程已用 F_body 物理前向核对（FL 50.0 mm 与指令一致）。
- 本次没有做闭环消融，不能据此判断 RL 策略在同一曲率下的表现，也不能把开环结果当作参考上限。
