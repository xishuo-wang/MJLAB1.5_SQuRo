# SQuRo_Hole 单板高度课程设计

## 单板几何

训练课程使用原 `HOLE_LAYOUT` 第一块板的几何：中心 X=0.2 m、Y=0、半长 0.015 m、半宽 0.1 m、厚度 0.01 m。`position.z` 表示板底。`HOLE_LAYOUT` 仍保留三块旧板，供旧配置和历史位置表可视化使用；单板配置由 `build_single_hole_entities` 构造。

板体是 mocap 实体。环境复位会重置 mocap 状态，因此每次写入采样板底后都要通过 `write_mocap_pose_to_sim` 重新写入。虚拟净空奖励、课程记录和诊断应读取 `mocap_pos` 中的实际高度，不能只读静态配置值。

## 高度查表规则

规则参数只定义在 `mdp/height_schedule.py`，可视化脚本与训练命令调用同一个 tensor 函数。设板的 X 范围为 `[x1,x2]`，板底为 `h`：

- `L=x1-0.150`、`R=x2+0.100`、`M=(x1+x2)/2`。
- 当 `h>=0.070` 时，每段自己的世界 X 落在 `[L,R]` 就取 `h-0.030`，否则取 0.055 m。
- 当 `h<0.070` 时，前段自己的世界 X 落在 `[L,M+0.04675)` 取 0.020 m；后段自己的世界 X 落在 `[M-0.04675,R]` 取 0.020 m。区间外取 0.055 m。
- 前段右端不包含，后段左端包含；高板两端边界均包含。

训练应使用 `F_body_Link` 与 `H_body_Link` 各自的实际世界 X。可视化采用 93.5 mm 前后中心距作为直行示意，低板边界偏移为 ±46.75 mm。理想中心距下，rootX=0.2 m 时前段位于不包含的低区上界、后段位于包含的低区下界，因此命令分别为基准高度和 0.020 m；这不是固定中心距下的双低情形。姿态变化可能压缩两中心间距并形成双低，生产命令始终根据每个躯干段的实际世界 X 独立查询。

高板严格使用 `h-0.030`，不设置 0.055 m 上限。板底为 0.090 m 时命令为 0.060 m；参考表仍按当前最近邻高度档选择 0.055 m，不做参考插值。

## 最低高度推进

`HeightCurriculumState` 提供可序列化的统计结构。只接受第三阶段、真实碰撞开启且课程采样启用的有效完成回合；所有合格高度都累计全高度统计，只有采样高度等于当前 `Zmin` 的回合进入最低档批次。未通过就超时、跌倒及其他失败都计入分母；已完成合法穿板、之后未跌倒的 12 秒超时回合仍计成功。每 256 个最低档回合封闭一批，通过率至少 60% 才累计连续达标批次；连续两批达标且当前档驻留不少于 100 iter 后，未来 reset 的 `Zmin` 下调 0.002 m，最低到 0.048 m。`Zmax` 保持 0.090 m。

推进只改变未来 reset 使用的采样范围；已有回合的板高保持不变。checkpoint 状态包括当前范围、驻留起点、批次计数、连续达标批数、各高度总计数和历史批次，可用于续训恢复。

终止监测使用 F/H 各九个 site。穿板时躯干采样点必须全部位于板宽内，板内点不得高于板底（允许 1 mm 数值容差）；经过上方或侧边会分别记录为高度超限或侧绕。成功要求先从前方进入，两个躯干在同一时刻都完全越过板后沿，且回合结束前没有跌倒。合法通过后自然结束的 12 秒 timeout 仍可成功。监测项始终返回 False，不改变原 12 秒终止时间；只有训练课程开启时才更新统计。课程推进在终止监测时同步完成，runner 每步消费回合快照用于日志。

训练阶段 1 为 0～1k iter，阶段 2 为 1k～2k iter；从 2k iter 的阶段 3 开始，runner 一次重建为单板并开启真实碰撞，之后只通过 reset 更新高度，不再重建环境。每回合为 12 秒（1200 步），默认训练预算 6000 iter。交互或无头评估可使用 `uv run python -B -m mjlab.scripts.SQuRo_Hole_curriculum_play --checkpoint <checkpoint> --no-show --steps 2000`；默认固定在 checkpoint 的当前 `Zmin`，指定 `--obstacle-height` 可固定其他合法板高，`--random-height` 则按 checkpoint 当前范围采样。评估不会推进课程，并将完成回合写入 CSV。

## 训练与验收

从头训练使用 `uv run train Mjlab-SQuRo-Hole --agent.logger tensorboard`。训练前两阶段保留原奖励数值，课程阶段沿用旧第四阶段的全部权重与 σ；仅净空奖励阈值改为读取每个环境的实际板底高度。动作仍为 14 维，观测仍为 113 维。

定向验收入口为 `uv run python -B -m mjlab.scripts.Hole.verify_hole_obstacle_curriculum`。它覆盖共享查表边界、成功率降档门控、状态序列化、真实 mocap 写入、部分复位、周期命令采样不移板，以及贴板通过、侧绕、上穿、跌倒和超时判据。

本次还验证了 CUDA 16 环境从 iter 1999 跨至 2001 的短训练：只重建一次，计数器保持连续；保存与加载可恢复最低高度、批次计数和连续达标批数。无头回放完成了 4 个真实 12 秒回合并导出 CSV。实际复位姿态移到板中央附近时，±46.75 mm 边界得到前后交替低姿态和约 0.0364 m/s 的速度命令；这项检查只覆盖复位姿态，不保证运动中间距压缩后没有双低。

这些验证证明课程、续训和回放能够运行，不代表正式训练已经收敛。6000 iter 完整训练与最低 48 mm 下的策略通过率仍需后续实验评估。
