## 单板几何

前三阶段（完整0～3000轮）仅创建机器人，不创建任何限高板。第四阶段通过 `build_single_hole_entities` 创建一块板：中心 X=0.2 m、Y=0、半长0.015 m、半宽0.1 m、厚度0.01 m；`position.z` 表示板底，编译初始值为0.070 m，随后按课程逐环境采样。几何唯一配置为 `config.py` 的 `HOLE_POSITION`、`HOLE_SIZE`，三板布局已移除。

板体是 mocap 实体。`hole_mocap_id` 按板体名称解析它自己的 mocap 下标；`entity.indexing.mocap_id` 指向框架的空 `mocap_base`，不能用来移动碰撞板。复位后由 `write_hole_bottom_z` 写入板体的 `mocap_pos`。虚拟净空奖励和课程记录读取同一板体高度；验收另用 `geom_pos_w.z` 减去编译模型的半厚度，独立检查真实碰撞板底，防止写读同一个错误下标仍通过。

2026-10-12_22-55-09 训练使用修复前版本 `50c1b9c`：课程场景的单板编译默认板底为 70 mm，错误写入空 mocap 导致物理板始终保持这一高度。该运行记录的 64 mm 等课程档仅是虚拟高度，不能作为对应真实板高的穿板通过率。`9c3450b` 修复后才真正执行逐回合板高采样；旧训练应保留作历史对照，修复后的课程需要重新训练。

## 高度查表规则

规则参数只定义在 `mdp/config.py`，阶段边界与阶段判定函数、共享查表函数及高度课程状态定义在 `mdp/curriculums.py`；可视化脚本与训练命令调用同一个 tensor 函数。设板的 X 范围为 `[x1,x2]`，板底为 `h`：

- `L=x1-0.150`、`R=x2+0.100`、`M=(x1+x2)/2`。
- 查表位置统一为 `base_Link` 的世界 X，即 `robot.data.root_link_pos_w[:, 0]`。
- 当 `h>=0.065` 时，离散挡位为：`[65,70)` mm→40 mm、`[70,75)` mm→45 mm、`[75,80)` mm→50 mm、`[80,+∞)` mm→55 mm。每次回合复位按50%概率选择等高或分段；等高在 `[L,R]` 内前后同取该挡位；分段在 `[L,M)` 内前端取该挡位、后端55 mm，在 `[M,R]` 内交换。区间外均为55 mm。
- 当 `h<0.065` 时，按板底高度离散到低姿态挡位：`[45,50)` mm→20 mm、`[50,55)` mm→25 mm、`[55,60)` mm→30 mm、`[60,65)` mm→35 mm。低于45 mm仍钳制到20 mm，当前课程下限保持46 mm。基座 X 在 `[L,M)` 内，前端取对应挡位、后端取55 mm；在 `[M,R]` 内，前端取55 mm、后端取对应挡位。区间外均为55 mm。
- 中点立即切到前高后低；外侧左右端点均包含。两个低姿态区间互斥。

两个命令调用同一个 `sample_base_heights`，不再使用前后躯干中心位置或固定中心距偏移决定阶段。脊柱侧摆、俯仰或整体偏航改变两段中心的 X 间距时，仍不能产生双低命令。短板区间为 `[0.035,0.315]` m，中点为 0.200 m；长板预览区间为 `[0.350,0.800]` m，中点为 0.600 m。

基座坐标仅用于高度命令阶段。净空奖励和完整穿出判据仍读取前后躯干的实际位置与采样点。新规则保证命令互斥，不保证实际姿态瞬时达到目标或切换时前躯干已经完全离板，后者需要训练与回放确认。

全部板高采用每5 mm一档的中心目标，并封顶于55 mm。高度模式阈值为40 mm（严格小于才为低），与65 mm板底分界衔接。低板受限侧直接使用20／25／30／35 mm标定角，参考相位速度为零；手动给出非节点高度时，参考查询仍支持标定表插值。另一侧沿用原运动步态，双高仍按最近邻高度档查表。板高课程初始范围仍为70～90 mm，最终下界仍为46 mm。

## 最低高度推进

`HeightCurriculumState` 提供可序列化的统计结构。只接受第四阶段、真实碰撞开启且课程采样启用的有效完成回合；所有合格高度都累计全高度统计，只有采样高度等于当前 `Zmin` 的回合进入最低档批次。未通过就超时、跌倒及其他失败都计入分母；已完成合法穿板、之后未跌倒的 12 秒超时回合仍计成功。每 256 个最低档回合封闭一批，通过率至少 60% 才累计连续达标批次；连续两批达标且当前档驻留不少于 100 iter 后，未来 reset 的 `Zmin` 在高于 0.050 m 时下调 0.002 m，在小于等于 0.050 m 时下调 0.001 m，最低到 0.046 m。`Zmax` 保持 0.090 m。

推进只改变未来 reset 使用的采样范围；已有回合的板高保持不变。checkpoint 状态包括当前范围、驻留起点、批次计数、连续达标批数、各高度总计数和历史批次，可用于续训恢复。

终止监测使用 F/H 各九个 site。穿板时躯干采样点必须全部位于板宽内，板内点不得高于板底（允许 1 mm 数值容差）；经过上方或侧边会分别记录为高度超限或侧绕。成功要求先从前方进入，两个躯干在同一时刻都完全越过板后沿，且回合结束前没有跌倒。合法通过后自然结束的 12 秒 timeout 仍可成功。监测项始终返回 False，不改变原 12 秒终止时间；只有训练课程开启时才更新统计。课程推进在终止监测时同步完成，runner 每步消费回合快照用于日志。

训练阶段 1 为 0～1k iter，阶段 2 为 1k～2k iter；阶段 3 为 2k～3k iter，复制第二阶段的高度池及全部既有奖励参数，仅增加全位置走廊惩罚。3k iter 的阶段 4 开始，runner 一次重建为单板并开启真实碰撞，之后只通过 reset 更新高度，不再重建环境。每回合为 12 秒（1200 步），默认训练预算 6000 iter。交互或无头评估可使用 `uv run python -B -m mjlab.scripts.SQuRo_Hole_curriculum_play --checkpoint <checkpoint> --no-show --steps 2000`；默认固定在 checkpoint 的当前 `Zmin`，指定 `--obstacle-height` 可固定其他合法板高，`--random-height` 则按 checkpoint 当前范围采样。评估不会推进课程，并将完成回合写入 CSV。

主回放脚本 `SQuRo_Hole_play` 中，课程阶段的 `obstacle_height=None` 优先读取检查点高度范围的 `Zmin` 作为板底，显式板高优先；热身阶段以及缺少高度课程记录时沿用保存的布局或配置默认，不能将尚未启用的课程下界当作当前板高。课程阶段的 `schedule` 模式还会将回放采样上下界都设为该最低档，每次复位保持同一板高，课程进度冻结。`fixed`/`random` 命令模式同样使用所选板高，但不会启用高度课程，场景构造和命令逻辑沿用原规则。需要范围随机采样时使用专用课程回放脚本的 `--random-height`。

## 全位置走廊约束

`corridor` 从 2000 iter 起启用，3000 iter 后继续保留；前两个阶段权重为零。它分别读取前、后躯干九个 site 的最高世界 Z，不按 X/Y 位置筛选点，也不依赖真实板体的位置。旧 `body_contact` 已删除。

两段的虚拟上限分别为 `h_F+offset`、`h_H+offset`；`offset` 由 `_CURVES["corridor_height_offset"]` 提供，在2000～3000 iter从30 mm线性降至 `BODY_HEIGHT_OFFSET=25 mm`，随后保持25 mm，不增加额外2.5 mm容差。20/55 mm命令的表面上限依次为2000轮50/85 mm、2500轮47.5/82.5 mm、3000轮后45/80 mm。高板未封顶时，最终虚拟上限不高于实际板底，分档下边界处恰好相等；板高超过80 mm时中心目标封顶55 mm，虚拟上限保持80 mm。

超限量为 `e=max(z_max-上限,0)`；走廊项为 `-w * mean(1-exp(-sigma*e²))`，在上限内恒为零，越低不会额外加分。权重 `w=5`、`sigma=2000` 都定义在 `_CURVES`。原高度跟踪奖励继续提供对称目标约束，避免仅靠单侧走廊导致无限降低姿态。

原 `body_contact` 在阶段 4 仍以权重 5 计算板底净空，阈值为实际板底减去 2.5 mm，空间范围与原公式保持一致。真实碰撞不会停用该奖励。此次没有同时修改其空间掩码、角度奖励批次依赖、位置表、模仿配比、脊柱尺度或 PPO 参数。

## 整体架构与设计变更

变更涉及任务命令、策略输入含义、奖励项及阶段切换时机，框架和 PPO 算法不变。旧命令为 `[vx,vy,vz,h_F,h_H,angle]`；新命令为 `[vx,h_F,h_H,gait_frequency,curvature,obstacle_height]`，前五列与 Backup 的顺序一致。策略观测仍为 113 维、动作仍为 14 维，但命令列含义已经改变，旧网络不能直接加载后继续训练或回放。

`config.py` 唯一定义列名与槽位，四阶段边界定义在 `curriculums.py`。`HoleCommand` 写入速度、目标高度、固定 2 Hz 步频、固定零曲率及板高先验；现有姿态奖励使用的零角度目标独立保存，不占命令列。参考生成读取步频列计算相位，并按步频比例输出关节速度。

前三阶段无实体，板高先验固定为 `WARMUP_OBSTACLE_HEIGHT=0.100 m`（100 mm），仅作为受限空间命令列的占位，不参与随机高度目标或速度生成。第四阶段记录逐环境的真实单板板底。复位、周期更新及外部板高修改后，有板场景的观测都读取同一真实板体。观测仍为113维、命令仍为6维；热身先验从原50 mm改为100 mm，旧热身检查点输入分布有变化，本轮按计划从头训练。

热身数据流为 `随机高度池＋固定100 mm先验 → 六维命令 → 参考与策略观测 → 策略动作`；真实课程为 `mocap板体 → 板高先验/高度查表 → 六维命令 → 参考与策略观测 → 策略动作`。runner在3000 iter从机器人场景重建为单板场景，保留步数和课程状态并重新取得观测；重建判据不再依赖启动时是否存在板体，从无板配置续训课程检查点也会在首次采样前创建板。

检查点 `hole_state` 记录 stage、collision、layout 与 height_course；版本字段已随版本审查一并删除。旧检查点可在其训练时版本（如 `1d25a45`）继续回放，本次训练必须从头开始。

默认日志分两组：速度与高度误差走 `Data/` 前缀（`Data/act_vel_x`、`Data/cmd_vel_x`、`Data/error_height_F`、`Data/error_height_H`）；高度课程四项为 `Metrics/Zmin_m`（当前最低板高）、`Metrics/success_rate`（当前最低档成功率）、`Metrics/failure_rate`（当前最低档失败率）、`Metrics/level_progress`（挡位推进进度 = 连续达标批数 / 所需批数），仅阶段 4 记录。原先的模式分组占比与方向误差、`课程/阶段`、`运动/侧向速度绝对值均值`、`走廊/*`、`vel_error_mean` 均已删除。

## 物理偏航与滚转奖励（2026-10-15）

复用 Backup 已验证的解剖坐标标定，将 `SPINE_FRONT_FRAME`、`SPINE_HIND_FRAME` 及刚体名称移至机器人公共模块 `asset_zoo/robots/SQuRo/SQuRo_constants.py`。Backup 原导入路径保留兼容，坐标数值与相对形变算法不变。Hole 只读取无状态的绝对姿态，不引入扭转展开历史或额外观测。

对 F/H 原生旋转分别右乘标定矩阵，得到物理坐标到世界的旋转 `R=R_native @ correction`，列向量为头向、左向、背向。采用 `R=Rz(yaw) @ Ry(pitch) @ Rx(roll)` 的欧拉约定：偏航 `atan2(R[1,0],R[0,0])` 来自头向在世界 XY 平面的投影；滚转 `atan2(R[2,1],R[2,2])` 表示绕物理纵轴的侧倾。纯俯仰不会产生滚转误差；接近竖直俯仰时欧拉分解存在奇异性，此任务目标姿态不在该区域。

`orientation` 改为前后物理偏航的圆周均值，误差 `atan2(mean(sin(yaw)),mean(cos(yaw)))`，目标仍为世界 +X。指数核 σ=5 与权重2/2/2/4保持数值不变，σ归入 `_CURVES`。圆周均值避免179°和−179°被算成0°；前后等大反向偏航可以抵消，这是整体平均朝向目标的含义，不能将该奖励解释为每段都笔直。

`angle` 不再使用原生 Euler roll 加减90°，改为两段物理滚转与0比较。用户确认保留高度模式：单低只约束低侧，双高约束两段，双低也约束两段并消除覆盖问题。双高和双低均先取各段绝对误差再相加，避免相反滚转抵消；保留双高σ=100、其余σ=50和权重1。

这是奖励目标修正，不保证与旧策略优化等效。旧 `angle` 在近直立区主要约束物理俯仰；修改后允许钻板所需的俯仰，同时约束侧滚。命令6维、观测113维、动作14维、参考表、模型、PPO与高度课程均未调整，旧检查点仍可用于推理对照。

## 前后独立的速度缩放（2026-10-17）

按用户更正后的规则，`v=BASE_SPEED*(s(h_F)+s(h_H))/2`，采用算术平均。20／25／30／35 mm因子依次为0、7/33、14/33、7/11；40／45／50／55 mm依次为8/11、9/11、10/11、1。20～35 mm之间按端点线性插值，35～40 mm之间延续 `h/55`，因此固定回放中的非节点高度也连续且单调。前后端独立计算，固定速度回放仍由显式参数覆盖。

## 高板等高与分段混合（2026-10-17）

真实碰撞课程的每次回合复位，板底高度和姿态策略独立采样；等高概率由 `HIGH_OBSTACLE_EQUAL_PROBABILITY=0.50` 唯一管理。逐环境选择保存在 `HoleCommand.obstacle_equal_height`，回合内周期命令重采样不会改变选择，部分复位只更新对应环境。低于65 mm始终采用既有分段规则；板底达到80 mm后目标封顶55 mm，两种策略的高度命令自然相同。

`HoleCommandCfg.high_obstacle_equal_height` 为 `None` 时按50%混合，为 `True` 时固定等高，为 `False` 时固定分段。训练默认混合。它只影响高板姿态规则，命令6维、观测113维、动作14维及课程成功门槛不变；模式通过现有前后高度命令体现，不增加独立观测槽。74 mm板底的等高命令为45／45 mm，分段为45／55→55／45 mm；后者按实际10 mm高度差产生约-0.185714 rad俯仰参考。

检查点 `hole_state.high_obstacle_equal_height` 保存配置选择，供回放读取；物理回合不续接，重建后按当前命令配置重新采样，续训策略由当前训练配置决定。主回放显式参数优先于检查点配置；未指定时，新增字段为 `None` 的检查点保持混合，缺少字段的旧检查点默认等高。`fixed`／`random` 命令来源不使用位置规则，仍按原命令含义执行。回放CSV增加 `obstacle_equal_height` 列，高板视频名增加 `equal`／`segmented`／`mixed` 后缀，避免同板高的两种验证互相覆盖。

uv run python -B -m mjlab.scripts.SQuRo_Hole_play --checkpoint-file <检查点> --obstacle-height 0.074 --high-obstacle-equal-height False
