# docs 目录说明

本目录混放了两套互不相关的文档，改文件前先确认属于哪一套。

## 本研究文档（`.md`，仓库根目录下 `*.md` 的延伸）

| 文件 | 内容 |
| --- | --- |
| `SQuRo_Backup_技术细节.md` | 翻正任务**参考手册**：当前配置、坐标系与判据陷阱、地面真值、时序、成功判据设计与标定、验收方法 |
| `SQuRo_Backup_奖励对照.md` | 翻正任务**实验日志**：每次改动的问题定位、改动内容、实测数据（按时间追加，不改历史条目） |
| `SQuRo_Backup_修改清单.md` | 翻正任务**状态与计划**：已完成/待办、已撤回方案与教训 |

三者分工：**技术细节 = 现状与原理**，**奖励对照 = 历史过程**，**修改清单 = 计划与状态**。
新增实验数据写进"奖励对照"；只有"当前配置"变了才动"技术细节"的开头一节。

## 上游 MJLAB 框架文档（Sphinx，本研究不使用）

`conf.py`、`index.rst`、`source/*.rst`、`_templates/` 是上游框架自带的 Sphinx 文档，
依赖 `pyproject.toml` 的 `docs` extra（sphinx-book-theme 等）。**与本研究无关，一般不要改**。

`Fig5/SQuRo-Fig5-Unified-Framework.pptx` 是论文插图源文件。
