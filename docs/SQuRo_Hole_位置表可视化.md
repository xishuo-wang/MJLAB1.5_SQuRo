# SQuRo_Hole 高度—位置表可视化

脚本：`src/mjlab/scripts/Hole/visualize_hole_schedule.py`。

## 展示内容

- 两个面板分别预览当前短板和长板对应的基座高度表；训练课程只使用第一块短板。
- 每块板有板底高度滑块和基座 X 滑块，板高范围为 48～90 mm。
- 蓝色实线和橙色虚线分别为前后躯干的目标高度。
- 一个竖向游标表示 `base_Link` 的位置，两个圆点显示同一时刻的前后命令。
- 读数包含基座世界 X、前后高度目标、模式、参考档位及速度命令。

短板读取 `config.py` 的真实课程几何，中心X=0.2 m、长30 mm；长板是可视化脚本内的独立示例，中心X=0.6 m、长200 mm，不进入训练场景。两块预览板厚10 mm，初始板底均为70 mm；滑块可调整到课程范围内任意高度。

## 基座高度表

设板底为 `h`，板的世界 X 范围为 `[x1,x2]`：

- `L=x1-0.150 m`。
- `M=(x1+x2)/2`。
- `R=x2+0.100 m`。

查表位置是 `base_Link` 的世界 X，不是前后躯干各自的中心 X。两个命令共用这一位置，固定中心距和 ±46.75 mm 偏移已移除。

| 板底 | 基座 X 区间 | 前端目标 | 后端目标 |
| --- | --- | --- | --- |
| `h>=0.070 m` | `[L,R]` | `h-0.030 m` | `h-0.030 m` |
| `h<0.070 m` | `[L,M)` | 0.020 m | 0.055 m |
| `h<0.070 m` | `[M,R]` | 0.055 m | 0.020 m |
| 两种情况 | 区间外 | 0.055 m | 0.055 m |

中点立即切到前高后低，左右外端点包含；两个低姿态区间互斥。短板的前低区间为 `[0.035,0.200)` m，后低区间为 `[0.200,0.315]` m；长板的两个区间为 `[0.350,0.600)` 与 `[0.600,0.800]` m。

高板严格使用 `h-30 mm`，不将目标截到55 mm。板底90 mm时目标为60 mm，现有参考表按最近邻选55 mm档，未引入插值。

## 使用方式

打开交互窗口，同时保存初始图片：

```powershell
uv run python -B -m mjlab.scripts.Hole.visualize_hole_schedule
```

指定板高，只导出图片：

```powershell
uv run python -B -m mjlab.scripts.Hole.visualize_hole_schedule --no-show --short-height 0.068 --long-height 0.070
```

默认输出到 `logs/rsl_rl/SQuRo_Hole/schedule_visualization/`，包含PNG、SVG和JSON参数记录。可用 `--output-dir` 指定目录。交互调整后的图像可通过工具栏保存。

横轴为基座相对起点的 X。默认 `--start-x 0`，相对坐标与世界坐标一致；非零起点时，板区间和曲线统一换算到相对坐标，查表仍使用世界 X。

## 与训练及回放的关系

曲线和游标读数调用 `mdp/curriculums.py` 中的生产函数 `sample_base_heights`；参数统一来自 `mdp/config.py`，训练命令和课程回放使用相同函数。旧三板位移表及其对照图已经移除，历史图可从 Git 版本 `7ad81be` 获取。

速度读数沿用 `compute_command_velocity`；低板单低组合速度约0.0364 m/s，新高度规则在课程范围内不生成双低零速命令。前三阶段的随机命令仍保留原有四种模式。

图中净空阈值是板底减去 `VIRTUAL_CLEARANCE_MARGIN`，与目标中心高度含义不同。本图验证命令规则；实际碰撞板底用课程验收中的 `geom_pos_w` 独立检查，实际策略穿板能力仍需回放评估。

完整0～3000轮训练无板，障碍物先验为固定100 mm占位，目标高度仍随机采样。本图的空间高度规则仅对应3000轮起的真实单板课程；占位值不用于本图查表。
