# SQuRo_Hole 高度—位置表可视化

脚本：`src/mjlab/scripts/Hole/visualize_hole_schedule.py`。

## 展示内容

- 上图展示历史三板训练的原始位置表，作为对照；当前课程仅使用第一块短板。
- 下图分别预览第一块短板和长板按新规则生成的目标高度。
- 每块板各有板底高度滑块与机体中点位置滑块，板高可在 48～90 mm 内调整，步长 0.1 mm。
- 蓝色实线、橙色虚线分别为前后躯干中心的目标高度；灰色矩形为板实体。
- 红色虚线为板底减去 `VIRTUAL_CLEARANCE_MARGIN` 的虚拟净空阈值。
- 两个游标分别表示前、后躯干的中心位置，圆点表示各自取样的目标高度。
- 黄色区域表示两条空间高度曲线的重叠区，不表示同一时刻两端同时压低。
- 读数显示两个中心位置、同一时刻的高度命令、高低模式、参考表档位及速度命令。

两种板的尺寸与位置来自 `entity.py` 的 `HOLE_LAYOUT`。短板位于 X=0.2 m，
长度 30 mm；长板位于 X=0.6 m，长度 200 mm；两者均厚 10 mm。
默认预览板底分别为当前配置的 50 mm 与 70 mm，每个板高滑块都可以跨越分界线。

## 新规则

设板底为 h，板的世界 X 区间为 [x1, x2]，定义：

- L = x1 − 0.150 m。
- M = (x1 + x2) / 2。
- R = x2 + 0.100 m。
- F1 = M + 0.04675 m，表示前段压低区间的结束位置。
- H0 = M − 0.04675 m，表示后段压低区间的开始位置。

默认高度使用任务常量 `BASE_HEIGHT=0.055 m`。
规则参数在 `mdp/height_schedule.py` 唯一定义，由训练命令和本可视化共用。

以下 X 是各段自己的中心位置：

| 板底高度 | 前段按 X_F 查表 | 后段按 X_H 查表 |
|---|---|---|
| h ≥ 0.070 m | X_F ∈ [L, R] 时取 h−0.030 m | X_H ∈ [L, R] 时取 h−0.030 m |
| h < 0.070 m | X_F ∈ [L, F1) 时取 0.020 m | X_H ∈ [H0, R] 时取 0.020 m |
| 两种情况 | 自己的区间外取 0.055 m | 自己的区间外取 0.055 m |

高板两条空间曲线一致，但同一时刻两段的 X 不同，进出区间时会先后变化。
低板曲线在 [H0, F1) 的空间位置重叠，不能把两条曲线在同一个 X 的值当作同一时刻命令。
前段结束端点不包含、后段开始端点包含，分别确定两条曲线的边界取值。
后段右端点 R 包含在区间内。
高板严格按 h−30 mm 计算，没有额外设置 55 mm 上限：板底 90 mm 时目标为 60 mm。

当前短板的前低区间为 [0.035, 0.24675) m，后低区间为 [0.15325, 0.315] m；
长板的前低区间为 [0.350, 0.64675) m，后低区间为 [0.55325, 0.800] m。
新规则区间直接由板几何计算，不沿用原位置表中 0.32、0.4、0.8 等节点。

## 同一时刻的示意

图示采用当前模型复位姿态的 93.5 mm 中心距作为直行示意：

- 中点位置为 X_C。
- 前段中心 X_F = X_C + 0.04675 m。
- 后段中心 X_H = X_C − 0.04675 m。

滑块移动 X_C，分别查询 X_F、X_H 对应的目标高度；模式和速度由这两个命令计算。
例如短板板底 50 mm、中点 X_C 分别为 0.199、0.200、0.201 m 时，
前段命令依次为 20、55、55 mm，后段命令依次为 55、20、20 mm。
X_C=0.200 m 时，前段恰好位于不包含的 F1 端点，后段位于包含的 H0 端点。

93.5 mm 是本图的直行几何示意。实际训练中应读取前后躯干各自的世界位置，
不应通过固定的 ±46.75 mm 偏移替代模型状态。
姿态变化可能压缩中心距并使两段同时落入各自低区间；这不是固定中心距示意的复位测量结论。

## 使用方式

打开交互窗口，同时保存初始图片：

```powershell
uv run python -B -m mjlab.scripts.Hole.visualize_hole_schedule
```

指定初始板高，只导出图片：

```powershell
uv run python -B -m mjlab.scripts.Hole.visualize_hole_schedule --no-show --short-height 0.070 --long-height 0.0699
```

默认输出到项目根下 `logs/rsl_rl/SQuRo_Hole/schedule_visualization/`，
包含 PNG、SVG 和 JSON 参数记录。可用 `--output-dir` 指定其他目录。
启动时导出的文件对应初始滑块值；交互调整后可通过图窗工具栏保存当前图像。

上图横轴为原位置表使用的机体位移；下图横轴为各段中心相对起点的 X 坐标。
默认起点 X=0，同时对应世界 X；使用 `--start-x` 时，板的位置、规则边界和中心游标
统一换算到相对坐标。

## 预览与训练的关系

原始对照曲线调用生产函数 `HoleCommand._update_command_from_schedule`。
下方空间曲线由 `sample_rule_schedule` 调用共享查表规则，同一时刻的两端命令由
`sample_body_commands` 分别按两个中心位置取样；旧位置表仍仅作为历史对照，参考表未改动。

速度读数调用现有 `compute_command_velocity`；参考表档位按照当前 `HEIGHT_LIST`
的最近邻规则计算，没有插值。例如板底 90 mm 对应目标 60 mm，但现有参考表仍取 55 mm 档。
本图用于验证目标曲线和边界，不代表实际机器人已经实现对应高度或能够穿板。
