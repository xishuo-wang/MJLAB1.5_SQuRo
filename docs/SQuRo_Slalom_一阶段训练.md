# SQuRo Slalom 一阶段训练与内侧包络约束

更新日期：2026-10-14。使用当前机器人模型，先训练曲率跟踪，再决定二阶段绕杆的可用曲率。

## Hole 索引对齐

`mdp/indices.py` 是驱动关节名称、执行器分组、闭链被动关节和足端名称的唯一入口。
执行器列序保持与 Hole 一致，14 维动作、117 维观测及参考表列序保持不变。
`ModelIndices` 只保存按名称解析的模型编号；执行器列分组直接使用 `_ACT_*` 常量。

- 复位的主动与被动关节按名称绑定，不再依赖 MuJoCo 数字编号。
- 颈部俯仰复位为 `-0.3 rad`，与当前模型及参考一致；这是本次索引迁移中实际改变的复位值。
- 参考表、模仿奖励、动作平滑、环境足端传感器和 CSV 记录同步使用集中定义。
- CSV 足端力按 `ContactSensor.primary_names` 解析，避免传感器列重排导致串腿。

## 固定一阶段

训练环境默认 `commands.slalom_cmd.phase0_only=True`，回放环境默认自动识别阶段。
该开关同时锁定路径、逐环境阶段、复位、杆可见性和奖励课程。
超过原来的 4000 轮边界仍使用一阶段；奖励课程停留在一阶段后半段，避免脊柱模仿权重进入二阶段。

| 轮次 | 曲率绝对值采样上限 | 行为 |
| --- | --- | --- |
| 0 | 0.5 | 小曲率热身 |
| 1000 | 12.75 | 均匀采样正负曲率 |
| 1500 | 18.875 | 扩展到更大曲率 |
| 2000 至 8000 | 25 | 持续训练完整范围 |

曲率归一化、参考表和速度缩放仍以 25 为上限，避免把 15 当成新的归一化常量改变已有映射。
本轮优化主要增加完整范围的训练轮次，并增强轨迹包络约束。
未增加高曲率过采样，也未改脊柱参考映射，便于根据首次训练结果决定下一项优化。

## 内外侧包络奖励

保持现有身体矩形投影和 40 mm 走廊半宽。对每段身体分别计算：

`内侧越界 = max(sign(κ) × 横向偏移 + 有效半宽 - 走廊半宽, 0)`

`外侧越界 = max(-sign(κ) × 横向偏移 + 有效半宽 - 走廊半宽, 0)`

正曲率以内侧左法向计量，负曲率相反；直行保持左右对称。
奖励为前后段平均：`exp(-σ × (外侧越界² + 2 × 内侧越界²))`。
两侧同时越界时分别累加，避免取最大值丢掉另一侧的越界。
这里的“2 倍”指平方误差项系数，不是最终奖励值直接减半。

参数唯一管理处是 `mdp/curriculums.py` 的 `_CURVES`：

- `corridor_inner_multiplier=2.0`。
- `sigma_corridor` 从 400 线性增加到 2500，0 至 2000 轮平滑收紧。
- 对应名义误差尺度 `1/sqrt(σ)` 从 50 mm 收紧到 20 mm，之后保持。
- 一阶段走廊总权重为 5，环境配置中的奖励权重保持 1.0。

例如最终尺度下，20 mm 外侧越界的单段归一化奖励约 0.368，内侧约 0.135。
原 `σ=20` 时同样 20 mm 越界的奖励约 0.992，区分度不足。
原 `Data/corridor_excess` 保留，新增 `Data/走廊内侧越界`、`Data/走廊外侧越界`、`Data/走廊误差尺度`。

该约束是路径切线方向的局部身体包络，不是机器人到真实杆的最小距离。
最大曲率 25 对应半径 40 mm，走廊半宽也为 40 mm，仅靠这个奖励无法保证杆体净空。
后续绕杆仍需检查头部、身体、腿部碰撞体与杆的净空，并通过真实碰撞回放确认。

## 手动训练

在项目根目录执行，默认从当前模型开始新训练：

```powershell
uv run python -B -m mjlab.scripts.train Mjlab-SQuRo-Slalom --agent.logger tensorboard --env.commands.slalom-cmd.phase0-only True
```

训练的默认预算为 8000 轮。本次未启动训练。
旧检查点仍能按原动作与观测尺寸加载，但模型、控制频率和奖励口径已有变化，加载兼容不代表策略效果等价。
直接恢复旧优化器与价值网络会沿用旧目标下的状态，应与新训练结果分别记录。

## 一阶段回放

```powershell
uv run python -B -m mjlab.scripts.SQuRo_Slalom_play --checkpoint-file "日志目录/model_6000.pt" --phase0-only True --fixed-curvature 20 --fixed-gait-freq 2
```

依次评估 `±15、±20、±25`，每个曲率分别测试 1 Hz、2 Hz 步频。
观察实际 XY 轨迹的拟合圆半径、方向误差、内外侧越界和跌倒情况，不只看平均回报。
倾斜机身的世界 Z 角速度除以前进速度，不等价于实际 XY 路径曲率。

回放默认读取检查点目录的 `params/env.yaml`，恢复保存的控制频率和 `phase0_only`。
也读取 `params/agent.yaml` 恢复动作裁剪。没有新阶段字段的历史训练仍自动按轮次识别阶段。
`--phase0-only True` 可以强制任何轮次检查点只验证一阶段；命令保持固定曲率，杆保持不可碰撞。
配置文件缺失时使用当前频率，并可显式指定阶段。
检查点加载恢复的旧全局步数会按回放识别出的轮次重新换算，避免 24/48 步口径混淆。
