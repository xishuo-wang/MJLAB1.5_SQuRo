# SQuRo Slalom 一阶段训练与内侧包络约束

更新日期：2026-10-14。使用当前机器人模型，先训练曲率跟踪，再决定二阶段绕杆的可用曲率。

## Hole 索引对齐

`mdp/indices.py` 是驱动关节名称、执行器分组、闭链被动关节和足端名称的唯一入口。
执行器列序保持与 Hole 一致，14 维动作、117 维观测及参考表列序保持不变。
`ModelIndices` 只保存按名称解析的模型编号；执行器列分组直接使用 `_ACT_*` 常量。

- 复位的主动与被动关节按名称绑定，不再依赖 MuJoCo 数字编号。
- 颈部俯仰复位为 `-0.3 rad`，与当前模型及参考一致；这是本次索引迁移中实际改变的复位值。
- 参考表、模仿奖励、动作平滑、环境足端传感器和 CSV 记录同步使用集中定义。
- CSV 足端力按 `ContactSensor.primary_names` 解析，避免传感器列重排导致串腿。

## 固定一阶段

训练环境默认 `commands.slalom_cmd.phase0_only=True`，回放环境默认自动识别阶段。
该开关同时锁定路径、逐环境阶段、复位、杆可见性和奖励课程。
超过原来的 4000 轮边界仍使用一阶段；奖励课程停留在一阶段后半段，避免脊柱模仿权重进入二阶段。

| 轮次 | 曲率绝对值采样上限 | 行为 |
| --- | --- | --- |
| 0 | 0.5 | 小曲率热身 |
| 1000 | 12.75 | 均匀采样正负曲率 |
| 1500 | 18.875 | 扩展到更大曲率 |
| 2000 至 8000 | 25 | 持续训练完整范围 |

曲率归一化、参考表和速度缩放仍以 25 为上限，避免把 15 当成新的归一化常量改变已有映射。
原一阶段训练配置增加了完整范围的训练轮次；本轮只修复圆环包络的几何口径。
未增加高曲率过采样，也未改脊柱参考映射，便于根据首次训练结果决定下一项优化。

## 内外侧包络奖励

2026-10-14 修复：一阶段使用同心圆环和实际姿态下的三维躯干包围盒投影。
二阶段仍使用原局部切线带，后续单独实现变曲率走廊与真实杆净距。

一阶段非零曲率的圆心为 `c = p_ref + n_ref / κ`，参考半径 `R = 1 / abs(κ)`。
前后体共用圆心，分别计算完整包络到圆心的最近距离 `d_min` 和最远距离 `d_max`：

`R_inner = max(R - CORRIDOR_HALF_WIDTH, POLE_RADIUS)`

`R_outer = R + CORRIDOR_HALF_WIDTH`

`内侧越界 = max(R_inner - d_min, 0)`

`外侧越界 = max(d_max - R_outer, 0)`

走廊半宽保持 40 mm，杆半径复用 `pole.py` 的 10 mm；首轮安全裕量为 0 mm。
因此曲率 15/20/25 的内半径为 26.7/10/10 mm，外半径为 106.7/90/80 mm。
曲率绝对值不超过 `1e-6` 时退化为对称直线带，仍使用当前躯干包络。
奖励为前后段平均：`exp(-σ × (外侧越界² + 2 × 内侧越界²))`。
两侧同时越界时分别累加，避免取最大值丢掉另一侧的越界。
这里的“2 倍”指平方误差项系数，不是最终奖励值直接减半。

参数唯一管理处是 `mdp/curriculums.py` 的 `_CURVES`：

- `corridor_inner_multiplier=2.0`。
- `sigma_corridor` 从 400 线性增加到 2500，0 至 2000 轮平滑收紧。
- 对应名义误差尺度 `1/sqrt(σ)` 从 50 mm 收紧到 20 mm，之后保持。
- 一阶段走廊总权重为 5，环境配置中的奖励权重保持 1.0。

例如最终尺度下，20 mm 外侧越界的单段归一化奖励约 0.368，内侧约 0.135。
原 `σ=20` 时同样 20 mm 越界的奖励约 0.992，区分度不足。
`Data/corridor_excess` 在一阶段记录每段 `max(内侧越界, 外侧越界)` 的平均值。
`Data/corridor_e_f`、`Data/corridor_e_h` 在一阶段为走廊半宽加该段越界量的等效距离，不能作为未截断径向距离使用。
`Data/走廊内侧越界`、`Data/走廊外侧越界` 分别记录前后体平均值；误差尺度口径保持不变。
二阶段日志保留原直线投影口径，不能直接比较两个阶段的越界统计。

### 当前模型包络标定

`indices.py` 按实体名称与全局编号读取已编译 MuJoCo 模型，将网格顶点经 `geom_quat/geom_pos` 变换到身体局部坐标。
`corridor.py` 为每个环境实例缓存两段局部三维轴对齐包围盒，随身体位置和完整四元数投影到 XY 平面。
网格与包围盒是保守包含关系；没有使用腹面九个 site 代替完整包络。

| 躯干 | 局部 X 范围 mm | 局部 Y 范围 mm | 局部 Z 范围 mm | 平放时前后长 / 左右宽 mm |
| --- | --- | --- | --- | --- |
| F_body | -30.5 至 30.5 | -23.5 至 21.0 | -54.35 至 8.95 | 63.3 / 61.0 |
| H_body | -30.5 至 30.5 | -21.0 至 23.5 | -10.65 至 27.35 | 38.0 / 61.0 |

旧二维矩形统一使用 80×70 mm，尤其高估了后体长度；新投影随侧倾变化，不固定使用上表的平放尺寸。
平放、切向、径向中心距为 `杆半径 + 身体半宽` 时，两段各自能够容纳在曲率 25 的 10 至 80 mm 圆环内。
该检验只证明单段几何可容纳，不证明连接后的整机姿态、闭链机构或步态动态可达。

最近距离检查十二条投影边，并通过分离轴判断圆心是否位于完整投影多边形内部；内部时最近距离为零。
最远距离检查八个投影角点。仅检查最近角点会遗漏边缘侵入圆心杆体的情况。
小曲率使用有理化径向偏差，避免大半径相减丢失毫米级误差。

圆环只约束 F/H 两个躯干的保守包络，内孔是圆心处的虚拟杆禁入区，奖励仍为软约束。
头部、腿部与真实杆净空尚需独立验收；二阶段平滑路径的曲率圆心也不一定是实际杆心。
前体速度/朝向与基座路径参考点的一致性及脊柱参考角标定，留作后续独立修改。

使用 `2026-10-14_01-22-33/model_7999.pt` 固定策略权重，分别测试 ±15/±20/±25 的 1 Hz、2 Hz，另加 2 Hz 直行。
每组运行 19 秒，统计排除起步 2 秒；13 组均无跌倒和非有限值。

| --- | --- | --- | --- |
| -25 / 2 Hz | 4.857 | 0.291 | 37.61 |
| +25 / 2 Hz | 4.623 | 0.615 | 39.43 |
| 0 / 2 Hz | 4.988 | 5.000 | 0.0013 |

同一条旧策略轨迹用两种几何口径重新计量，奖励下降说明原策略未满足新的圆环目标，不能解释为修改导致策略控制退化。
旧策略在高曲率下主要超出外边界；内孔边缘侵入的处罚已通过独立几何用例验证。
静态保持根部位置、直接替换为旧线性脊柱参考角，也不能使圆环奖励自动提高；该过程未求解闭链约束，不能当作动态姿态验收。
本次没有修改 PPO、策略频率、命令曲率上限、脊柱参考映射或其他奖励权重。
首轮建议新开一阶段训练，走完整的曲率和 σ 课程；直接恢复末轮检查点会从最终课程和旧探索状态开始。
动作/观测仍为 14/117 维，旧 actor 可加载；新奖励下的价值函数需要重新学习。

## 手动训练

在项目根目录执行，默认从当前模型开始新训练：

```powershell
uv run python -B -m mjlab.scripts.train Mjlab-SQuRo-Slalom --agent.logger tensorboard --env.commands.slalom-cmd.phase0-only True
```

训练的默认预算为 8000 轮。本次未启动训练。
旧检查点仍能按原动作与观测尺寸加载，但模型、控制频率和奖励口径已有变化，加载兼容不代表策略效果等价。
直接恢复旧优化器与价值网络会沿用旧目标下的状态，应与新训练结果分别记录。

## 一阶段回放

```powershell
uv run python -B -m mjlab.scripts.SQuRo_Slalom_play --checkpoint-file "日志目录/model_6000.pt" --command-source 转圈 --fixed-curvature 20 --fixed-gait-freq 2
```

依次评估 `±15、±20、±25`，每个曲率分别测试 1 Hz、2 Hz 步频。
观察实际 XY 轨迹的拟合圆半径、方向误差、内外侧越界和跌倒情况，不只看平均回报。
倾斜机身的世界 Z 角速度除以前进速度，不等价于实际 XY 路径曲率。

回放默认读取检查点目录的 `params/env.yaml`，恢复保存的控制频率和 `phase0_only`。
也读取 `params/agent.yaml` 恢复动作裁剪。没有新阶段字段的历史训练仍自动按轮次识别阶段。
`--command-source 转圈` 可以强制任何轮次检查点只验证一阶段；命令保持固定曲率，杆保持不可碰撞。
`fixed_velocity` 保留基础速度含义，最终速度再乘步频与曲率缩放。
配置文件缺失时使用当前频率，并可显式指定阶段。
检查点加载恢复的旧全局步数会按回放识别出的轮次重新换算，避免 24/48 步口径混淆。
