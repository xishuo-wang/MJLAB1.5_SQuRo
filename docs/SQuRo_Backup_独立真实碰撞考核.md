## 当前协议

| 项目 | 处理方式 |
| --- | --- |
| 阶段一 | 保留原来 0～3000 轮的无墙碰撞训练、参考和奖励课程 |
| 阶段二训练 | 3000 轮起保留真实墙碰撞；每回合墙位固定，循环部分复位沿用本回合墙位 |
| 独立考核 | 另一套真实碰撞环境，冻结确定性策略与观测归一化；不向 PPO 存储写样本 |
| 考核时机 | 预训练 500 轮，3500 轮开始；普通模式每 100 轮一次，最终模式每 500 轮一次 |
| 考核规模 | 每次两批，每批 1024 环境，每环境只计一次首次尝试；全部结果收齐即退出 |
| 考核时长 | 首次成功、阶段重试/重新开始或超时即结束该样本；当前最长 6.87 s，训练回合仍为 12 s |
| 成功条件 | 首次翻正确认前无阶段重试或重新开始；复用 S2 姿态条件和 0.10 实际秒连续确认，不附加站稳或关节速度要求 |
| 普通模式 | 每批最低档至少 256 个有效回合，首次尝试翻正率至少 60%；两批全部完成后在同档位一次结算 |
| 推进 | 每档驻留至少 100 轮，通过一次完整考核后 `d_min` 减少 1 cm，直到 6 cm |
| 退档 | 连续 5 次完整考核失败后放宽一档；退档后需连续两次完整考核达标才重新推进 |
| 最终模式 | 最低档通过后改为全间距区间考核；两批全范围首次尝试翻正率分别达到 80% 才记录最终验收通过 |
| 后续考核 | 最终验收通过后仍继续考核，已通过标志保留；各档成绩继续反馈训练采样权重 |

S2 沿用两条姿态路径：前后段都正置且躯干高度均低于 4 cm，或满足现有双段站立几何。前一路使用原来的 45° 朝向容差；后一路仍要求余弦大于 0.9、高度大于 5 cm。没有将中间高度区间改成成功，也没有修改奖励侧的阶段推进时窗。

`righting_time_out` 在物理步结束、超时复位之前记录翻正确认，返回值仍是原来的回合超时条件。`_ep_righted` 在完整回合内锁存，循环部分复位不会清空；完整回合结束时发布 `_last_ep_righted` 与该回合实际墙位，再清空当前回合标记。提前结束的首次尝试直接读取当前翻正和墙位，超时末步读取发布快照；训练端原有首回合无效标记只用于训练诊断。

独立考核 runner 在每次 `step()` 后立即收集首次尝试结果：首次确认前出现 P1/P2 重试、阶段回退标志或循环部分复位即判失败，之后再翻正也不补分；首次成功立即计成功。同一步既有翻正确认又有重试时按失败计。到时长上限仍未确认也计失败，异常提前复位或缺少首次尝试结果则拒绝结算。初始仰卧和正常姿态波动不单独判失败，不使用包含初态的 `Progress/relapse` 作为回退依据。

每个环境只记录一个结果，不等待回合超时或第二次尝试；整个并行批次在最后一个首次尝试结束后退出。评估命令启用 `single_attempt_evaluation=True`，稳定站立完成也不再重启第二个翻正循环，循环完成最多记录一次；训练默认关闭该选项，保留原有循环复位。

时长上限从现有时间窗推导：`(P1_END + P1_SETTLE_MAX + T3) × TIME_SCALE_MAX + 2 × window_late_s + 2 × step_dt`，并取不超过原训练回合长度的值。当前为 `1.95 × 3 + 2 × 0.50 + 2 × 0.01 = 6.87 s`，覆盖最慢 λ 下 P1、P2 的首次允许窗口与离散边界，不缩短阶段本身的宽限时间。多数样本会在上限前完成，批次实际时长由最慢未结束样本决定。

日志 `Curriculum/eval_first_attempt_righting_rate` 用于课程推进；分箱日志为 `Curriculum/bin{i}_first_attempt_righting_rate`，难例权重同步使用首次尝试成绩。缩短评估不再计算或输出旧 `Curriculum/eval_righting_rate`，避免冒充原来的“12 s 内曾翻正率”。每个诊断样本包含耗时和结束原因，考核 JSON 记录成功条件与时长上限。训练端 `p_done` 仍表示严格稳定站立。

## 几何与采样

负 X 墙中心为 `-d`，正 X 墙中心固定为 `+0.05 m`。每侧墙半厚保持 `0.01 m`，因此内侧净宽为：

`clear_width = d + 0.05 - 2 × 0.01 = d + 0.03 m`

课程从 `d_min=0.20 m` 起，每档减少 `0.01 m`，最终 `d_min=0.06 m`，对应墙中心间距 `0.11 m`、内侧净宽 `0.09 m`。原随机课程已经使用 6 cm 的负墙距离下界；这次同步把遗留离散墙位表的终点从 `-0.05 m` 改为 `-0.06 m`，消除旧路径里的 8 cm 净宽终点。

区间边界为 `0.06, 0.07, …, 0.20 m`，共 14 个连续区间，左闭右开、末区间含上限。普通模式保留 30% 当前下界定点采样；其余 70% 在当前范围内先选区间，再在区间内均匀采样。区间初始权重为 1，初始连续分布与旧均匀采样一致。考核结束后训练权重更新为：

`weight_i = 1 + 2 × max(0, target - success_rate_i)`

普通模式目标为 0.60，最终模式目标为 0.80；无样本区间的权重保持 1。考核始终使用等区间权重，不继承训练侧的难例加权。最终模式取消下界定点采样，覆盖全部 14 个区间。训练端仍按考核反馈加权。

`WallCurriculumState` 只接收完整批次的独立首次尝试结果。训练端 `p_stood / p_onset / p_done` 保留作诊断，不能推进课程。两批之间不改变档位；缺样本、混入其他档位、重复环境或中途异常都不能推进或最终验收。换档后的日志保留最近一次考核成绩。

## 保留参数与训练影响

保留 14 维动作、116 维 actor/critic 观测、9 维命令、动作缩放 0.3、12 s 回合、0.002 s 物理步长与 decimation=5、求解器 100/50、96 步 rollout、1024 训练环境、9000 轮预算、网络与全部 PPO 超参数。奖励公式、权重与 σ、参考表、参考时间缩放、P1 冗余时间课程、墙尺寸与接触参数均沿用修改前源码。

训练与评估均开启真实碰撞，使策略仍可利用侧墙接触完成翻正，不额外加入自由空间包络限制。课程的停留时间、退档、最终模式与难例采样会改变训练样本分布，不能承诺策略效果保持不变或必然提高。普通模式每 100 轮额外运行两批提前结束的考核，当前每批最多约 687 个控制步，相对训练的 9600 步最多约 14.3% 环境步开销，另有创建环境的开销；训练步数与预算计数不增加。

## 检查点、回放与兼容

新检查点在 `infos.corridor_state.wall_course` 保存完整课程，`version=2` 表示首次尝试计分：当前下界、驻留起点、连续通过/失败、退档状态、最终验收、区间权重与历史。保留原有扁平 `wall_d_min` 和墙位字段，既有回放入口仍默认取课程下界；显式固定墙位优先。

恢复 `version=1` 的整回合考核检查点时，保留模型、优化器、训练进度与当前墙距，清空旧考核通过/失败计数、历史、最终通过标记和难例权重；驻留起点设为恢复的训练轮数，在当前墙距重新考核，不退回最宽挡位。旧训练目录和检查点不改写。`version=2` 完整恢复新标准课程，不重复清空。

旧检查点恢复模型、优化器与训练步数，迁移保存的 `wall_d_min`；没有该字段时按记录墙位迁移。旧训练批次不能作为新独立考核成绩继承；越过新下界的旧自动课程会明确警告并限制到 `d_min=0.06 m`。仅加载 actor 的回放保持入口编译好的场景，不强行替换用户指定的旧几何。

固定墙位或固定时间缩放的诊断入口不自动推进课程。自动考核仅支持单卡训练。考核隔离 Python、NumPy、Torch CPU/CUDA 随机状态，结束或异常后恢复训练模式；关闭考核环境失败不会阻止最终检查点与日志关闭。

考核沿用训练的 NaN 检查，异常时拒绝结算并保留退出清理流程。原有 `verify_corridor_wiring` 将机器人中心强制置于墙中心，开碰撞时虽产生接触，40 步后位置出现 NaN；该脚本的旧断言只验证接触存在，不能作为数值稳定性证据。本次未改墙接触与求解器参数，正常回合的运行验证以带 NaN 检查的独立考核和短程训练为准。
