# SQuRo_Backup 独立真实碰撞考核（2026-10-22）

## 版本与范围

修改前源码已归档为 Git 标签 `SQuRo_Backup-v0.1`（`d22dca9`）。最近的正式 Backup 训练为 `2026-09-27_14-33-27_v1/model_8999.pt`，训练目录内的 Git 快照是 `backup-v1`（`e1343b4`），并记录了干净工作区。这两个版本不同，不以检查点可加载证明训练环境等价。

索引统一为独立提交 `9b3a04d`，见 [索引统一说明](SQuRo_Backup_索引统一.md)。本次课程改动以 `SQuRo_Backup-v0.1` 为参数基线，只改变二阶段课程推进与考核采样协议；不添加奖励项。

## 当前协议

| 项目 | 处理方式 |
| --- | --- |
| 阶段一 | 保留原来 0～3000 轮的无墙碰撞训练、参考和奖励课程 |
| 阶段二训练 | 3000 轮起保留真实墙碰撞；每回合墙位固定，循环部分复位沿用本回合墙位 |
| 独立考核 | 另一套真实碰撞环境，冻结确定性策略与观测归一化；不向 PPO 存储写样本 |
| 考核时机 | 预训练 500 轮，3500 轮开始；普通模式每 100 轮一次，最终模式每 500 轮一次 |
| 考核规模 | 每次两批，每批 1024 环境，每环境只计首个完整 12 s 回合 |
| 成功条件 | 复用现有 S2 姿态条件，连续确认 0.10 实际秒；不附加阶段时窗、站稳时长或关节速度要求 |
| 普通模式 | 每批最低档至少 256 个有效回合，翻正率至少 60%；两批全部完成后在同档位一次结算 |
| 推进 | 每档驻留至少 100 轮，通过一次完整考核后 `d_min` 减少 1 cm，直到 6 cm |
| 退档 | 连续 5 次完整考核失败后放宽一档；退档后需连续两次完整考核达标才重新推进 |
| 最终模式 | 最低档通过后改为全间距区间考核；两批整体翻正率分别达到 80% 才记录最终验收通过 |
| 后续考核 | 最终验收通过后仍继续考核，已通过标志保留；各档成绩继续反馈训练采样权重 |

S2 沿用两条姿态路径：前后段都正置且躯干高度均低于 4 cm，或满足现有双段站立几何。前一路使用原来的 45° 朝向容差；后一路仍要求余弦大于 0.9、高度大于 5 cm。没有将中间高度区间改成成功，也没有修改奖励侧的阶段推进时窗。

`righting_time_out` 在物理步结束、超时复位之前记录翻正确认，返回值仍是原来的回合超时条件。`_ep_righted` 在完整回合内锁存，循环部分复位不会清空；完整回合结束时发布 `_last_ep_righted` 与该回合实际墙位，再清空当前回合标记。首个完整考核回合可计分；训练端原有首回合无效标记仍用于训练诊断。

## 几何与采样

负 X 墙中心为 `-d`，正 X 墙中心固定为 `+0.05 m`。每侧墙半厚保持 `0.01 m`，因此内侧净宽为：

`clear_width = d + 0.05 - 2 × 0.01 = d + 0.03 m`

课程从 `d_min=0.20 m` 起，每档减少 `0.01 m`，最终 `d_min=0.06 m`，对应墙中心间距 `0.11 m`、内侧净宽 `0.09 m`。原随机课程已经使用 6 cm 的负墙距离下界；这次同步把遗留离散墙位表的终点从 `-0.05 m` 改为 `-0.06 m`，消除旧路径里的 8 cm 净宽终点。

区间边界为 `0.06, 0.07, …, 0.20 m`，共 14 个连续区间，左闭右开、末区间含上限。普通模式保留 30% 当前下界定点采样；其余 70% 在当前范围内先选区间，再在区间内均匀采样。区间初始权重为 1，初始连续分布与旧均匀采样一致。考核结束后训练权重更新为：

`weight_i = 1 + 2 × max(0, target - success_rate_i)`

普通模式目标为 0.60，最终模式目标为 0.80；无样本区间的权重保持 1。考核始终使用等区间权重，不继承训练侧的难例加权。最终模式取消下界定点采样，覆盖全部 14 个区间。训练端仍按考核反馈加权。

`WallCurriculumState` 只接收完整独立考核结果。训练端 `p_stood / p_onset / p_done` 保留作诊断，不能推进课程。两批之间不改变档位；缺回合、混入其他档位、重复环境或中途异常都不能推进或最终验收。换档后的日志保留最近一次考核成绩。

## 保留参数与训练影响

保留 14 维动作、116 维 actor/critic 观测、9 维命令、动作缩放 0.3、12 s 回合、0.002 s 物理步长与 decimation=5、求解器 100/50、96 步 rollout、1024 训练环境、9000 轮预算、网络与全部 PPO 超参数。奖励公式、权重与 σ、参考表、参考时间缩放、P1 冗余时间课程、墙尺寸与接触参数均沿用修改前源码。

训练与评估均开启真实碰撞，使策略仍可利用侧墙接触完成翻正，不额外加入自由空间包络限制。课程的停留时间、退档、最终模式与难例采样会改变训练样本分布，不能承诺策略效果保持不变或必然提高。普通模式每 100 轮额外运行两次 1200 步考核，相对训练的 9600 步增加约 25% 环境步开销，另有创建环境的开销；训练步数与预算计数不增加。

## 检查点、回放与兼容

新检查点在 `infos.corridor_state.wall_course` 保存完整课程：当前下界、驻留起点、连续通过/失败、退档状态、最终验收、区间权重与历史。保留原有扁平 `wall_d_min` 和墙位字段，既有回放入口仍默认取课程下界；显式固定墙位优先。

旧检查点恢复模型、优化器与训练步数，迁移保存的 `wall_d_min`；没有该字段时按记录墙位迁移。旧训练批次不能作为新独立考核成绩继承；越过新下界的旧自动课程会明确警告并限制到 `d_min=0.06 m`。仅加载 actor 的回放保持入口编译好的场景，不强行替换用户指定的旧几何。

固定墙位或固定时间缩放的诊断入口不自动推进课程。自动考核仅支持单卡训练。考核隔离 Python、NumPy、Torch CPU/CUDA 随机状态，结束或异常后恢复训练模式；关闭考核环境失败不会阻止最终检查点与日志关闭。

考核沿用训练的 NaN 检查，异常时拒绝结算并保留退出清理流程。原有 `verify_corridor_wiring` 将机器人中心强制置于墙中心，开碰撞时虽产生接触，40 步后位置出现 NaN；该脚本的旧断言只验证接触存在，不能作为数值稳定性证据。本次未改墙接触与求解器参数，正常回合的运行验证以带 NaN 检查的独立考核和短程训练为准。
