# SQuRo_Hole 索引审查与基线等价验收

## 比较基线

本轮以第一批完成后的 `929a2a3` 为基线，继续在 `Hole_baseline` 修改。
不迁入 `main` 的奖励公式、轴缩放、hind_hold 或 mocap 随机化。

- 后腿保持角：`(0.80, -0.15)`，不是 `9947edc` 的 `(0.80, -0.12)`。
- 三块板底：`0.05 / 0.07 / 0.05 m`。
- 模仿公式：`r_leg + r_spn + r_neck`。
- 脊柱位置 σ：`(5, 10, 10, 5)`；速度 σ：四阶段均为 `0.1`。
- 脊柱逐轴缩放：`(1.5, 0.7, 1.5, 0.7)`。
- 注册奖励仍为 11 项，动作 14 维、观测 113 维，48 步/iter。

## 索引职责

`mdp/indices.py` 管理执行器分组、参考表部位列区间、闭链被动关节名称、
足端名称及模型编号解析。世界 XYZ、四元数 WXYZ 和 MuJoCo 字段分量编号不属于机器人索引。

参考表继续使用“前腿、后腿、脊柱、头颈”的内部布局，出口转换到执行器顺序。
`resolve_joint_ids()` 的参考表序兼容接口保留；`stop` 改用
`resolve_actuator_joint_ids(robot, _ACT_F_LEG_IDS)`，不再假定前四列是前腿。

复位仍按“腿、脊柱、闭链被动关节、头颈”绑定原有角值，但所有模型编号按名称解析。
足端 CSV 按 `ContactSensor.primary_names` 查找力列，不依赖传感器的自然展开顺序。

参考表脊柱局部序为 `(F_spine1, F_body, H_spine1, H_body)`。
原来的局部列 2 实际是 **H_spine1**，完整参考表列 10 同样是 H_spine1；
该角仍为 `-0.65`，F_spine1 为 0。旧技术文档把此处写成 F_spine1 是文档错误。
自检的脊柱、后腿读数及 `//24` 轮次换算已按真实列和 `STEPS_PER_ITER` 修正。

## 验收

本节记录第一批索引迁移的历史验收。2026-10-13 的模块整理删除了本节所述三个迁移对拍脚本；历史源码可从 Git `7ad81be` 获取。当前验收入口及数值等效证据见 `../../../README.md` 与历史记录 `SQuRo_Hole_高度课程设计.md`。

`uv run python -B -m mjlab.scripts.Hole.verify_hole_index_equivalence` 默认从 Git 装载
`929a2a3` 的对照模块，不检出旧版本、不改工作区。也可用 `--baseline <提交>` 指定版本。

- 完整六张参考表、相位和周期数据逐位比较。
- 真实模型的复位关节角、速度和基座状态逐位比较。
- 四阶段、25 个高度组合、六相位、三种非对称速度状态，对照全部已注册奖励。
- 单独检查前腿运动与脊柱颈部运动的 stop 区分，以及身体编号、足端力列重排。
- 数值签名比较器拒绝 NaN/Inf；导出时禁止非有限数。
- 检查全部奖励查询键，并模拟脊柱 σ 键缺失或拼错，要求明确报错。

## 未启用奖励的遗留问题

以下问题属于历史记录；六个未注册奖励函数及其课程参数已经在 2026-10-13 的模块整理中删除，不再保留未接入训练的实现。

`energy/cot` 把参考表顺序的速度与执行器顺序的力矩相乘，存在部位错位。
`action_acc` 仍假定 12 维动作和三帧历史，与当前 14 维、两帧动作历史不符。
这些函数未注册到训练环境；修复会改变函数数值，本轮保持原定义并不启用。
角度奖励的混合模式共用 σ、双高误差求和等旧行为也保持原样。

## 课程查询的缺键处理

当前训练分支的脊柱 σ 键完整，其四阶段数值保持第一批基线口径。
`get_curriculum_reward_weight` 不再对未知键静默返回 1.0，
删除 σ 或拼错参数名时会抛出带参数名称的 `KeyError`。

六个未注册奖励 `energy/cot/joint_acc/y_offset/joint_limits/action_acc`
此前依赖缺键默认值，现在在 `_CURVES` 显式定义为四阶段 1.0。
它们未接入训练；此项仅保留原数值，使所有现存奖励查询键都有定义。
原有奖励权重、σ、配比、课程边界及模仿公式均保持不变。
最终 JSON 签名的课程元数据会多出上述六个键；严格结构比较会报告这些新增定义。
数值等价脚本同时查询历史缺键默认值与现有显式曲线，四阶段取值完全一致。
