# SQuRo_Hole 回放与工具

本文件汇总训练之外的入口：策略回放、无策略参考回放、检查点评估、高度-位置表可视化、诊断脚本与验收命令。所有脚本都在项目根目录用 `uv run` 执行；建议先设置：

```powershell
$env:PYTHONIOENCODING='utf-8'; $env:PYTHONDONTWRITEBYTECODE='1'; $env:UV_CACHE_DIR="$env:TEMP\uv_cache_mjlab"
```

训练标准入口：

```powershell
uv run train Mjlab-SQuRo-Hole     # 默认 wandb；如需纯本地标量: --agent.logger tensorboard
```

## 1. 策略回放（`SQuRo_Hole_play.py`）

```powershell
uv run python -B -m mjlab.scripts.SQuRo_Hole_play --checkpoint_file <model_xxx.pt>
```

主要参数（`tyro` 命令行）：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--agent` | `trained` | `zero` / `random` / `trained` |
| `--checkpoint_file` | 无 | 本地检查点路径；也可用 `--wandb_run_path` + `--wandb_checkpoint_name` |
| `--num_envs` | 1 | 回放环境数 |
| `--video` | True | 录制视频到输出目录 |
| `--command_source` | `schedule` | `schedule` 跟随训练高度规则；`fixed` 用 `--fixed_height_f/h`；`random` 随机池 |
| `--fixed_velocity` / `--fixed_height_f` / `--fixed_height_h` | None / 0.055 / 0.020 | `fixed` 模式使用 |
| `--collision` | True | 覆盖板体碰撞开关；显式优先于检查点记录 |
| `--obstacle_viz` | True | 只改外观，不影响碰撞 |
| `--high_obstacle_equal_height` | None | 高板等高/分段；None 沿用检查点 |
| `--obstacle_height` | 0.065 | 覆盖板底高度（m） |

行为要点：

- 回放会读取检查点的 `obstacle_state`（`env_state` 缺失时退回默认步数 0），恢复课程高度与单板几何；旧检查点无该记录时按默认课程状态。
- 板底高度优先级：显式 `--obstacle_height` > 检查点课程状态 > 默认初始值；碰撞优先级：显式 `--collision` > 检查点记录 > 训练默认关闭。
- 视频与 CSV 默认写到 `<run>/videos/`；单板可见性开关只改外观。
- 回放跑完整 6D 命令，不是“固定高度直线钻板”，评估穿板能力时需自行看成功率/视频。

## 2. 无策略参考回放（`SQuRo_Hole_Replay.py`）

脚本顶部直接配置参数（不解析命令行），运行：

```powershell
uv run python -B -m mjlab.scripts.SQuRo_Hole_Replay
```

```python
HEIGHT_F = 0.055
HEIGHT_H = 0.055
VISUALIZE = "viewer"   # viewer / video / none
DURATION = 10.0
ENABLE_COLLISION = False
OUTPUT_DIR = Path("logs/rsl_rl/SQuRo_Hole/reference_replay")
```

用途：不加载策略，按位置控制直接回放参考关节轨迹，用于核对参考表/IK/关节范围与物理一致性。

- 调用 `reference.get_reference_joint_state`，沿用模式判定、最近高度档、相位离散采样与头颈参考；不复制公式、不改参考表与执行器参数。
- 用动作项运行时的关节顺序/缩放/偏置把参考角转成位置控制；绕过 PPO/RSL-RL 动作裁剪，模型控制范围与物理限位仍生效。
- 固定前后高度并关闭高度课程；`ENABLE_COLLISION=False`（默认）不建板，板高先验为 100 mm 占位；设为 True 会创建真实单板但高度不随位置切换。
- 输出：`reference.csv`（参考/实际关节角速度、力矩、控制目标、前后高度、位移/速度、身体表面最高点）、`joint_tracking.png`、`height_tracking.png`、`reference.mp4`（video 模式）。
- 判读：启动即报关节限位冲突，说明参考与模型不一致；参考在范围内但实际明显偏离，则要查执行器力矩、闭链约束与地面接触，不能只归因于轨迹公式。躯干高度跟踪不等于身体表面净空。

## 3. 检查点评估（`Hole/evaluate_checkpoints.py`）

```powershell
uv run python -B -m mjlab.scripts.Hole.evaluate_checkpoints --checkpoint <model.pt> [--checkpoint <model2.pt>]
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--checkpoint` | 必填，可重复 | 课程检查点 |
| `--heights` | `0.047 0.048 0.049 0.055` | 真实板底高度列表（m） |
| `--samples` | 32 | 每档随机回合数（另加 1 个确定性回合） |
| `--seed` | 42 | 评估种子 |
| `--device` | `cuda:0` |  |
| `--high-obstacle-mode` | `saved` | `saved` / `equal` / `segmented` / `mixed` |
| `--output-dir` | `logs/diagnostics/SQuRo_Hole/checkpoint_evaluation` | 输出目录 |

- 只接受已进入单板课程（stage 4）的检查点；否则直接报错。
- 冻结网络与观测归一化，按指定真实板高统计完整穿板回合（成功/失败码/最大 X 等），输出 JSON。
- 与训练不同：这里强制开启板体碰撞，是“真实接触”口径；训练侧 `Metrics/训练无碰撞几何通过率` 只是虚拟几何诊断。

## 4. 高度-位置表可视化（`Hole/visualize_hole_schedule.py`）

```powershell
uv run python -B -m mjlab.scripts.Hole.visualize_hole_schedule
uv run python -B -m mjlab.scripts.Hole.visualize_hole_schedule --no-show --short-height 0.068
```

- 两个面板分别预览当前训练用的短板和脚本内置的长板示例；训练只使用短板（中心 X=0.2 m、半长 0.015 m、半宽 0.3 m）。
- 每块板有板底高度滑块与基座 X 滑块；蓝色实线/橙色虚线分别为前后目标高度，竖线是 `base_Link` 世界 X，圆点为同一时刻命令。
- 读数包含基座世界 X、前后高度目标、模式、参考档位与速度命令；板高范围 47～90 mm，默认板底 70 mm。
- 目标高度由生产函数 `compute_base_heights` 计算：板底按 5 mm 分桶映射到 `HEIGHT_LIST`；高板每回合等高/分段（50%）；低板按 `base_Link` 所在区间取低侧目标、另一侧 55 mm，区间外均 55 mm。具体边界以 `obstacle_rule_bounds` 与 `height_bin_indices` 为准（左闭右开、float32 分桶）。
- 默认输出到 `logs/rsl_rl/SQuRo_Hole/schedule_visualization/`（PNG/SVG/JSON），可用 `--output-dir` 指定。

## 5. 其他诊断脚本

| 脚本 | 用途 |
| --- | --- |
| `Hole/analyze_training.py` | 读取 TensorBoard `events.out.tfevents.*`，汇总奖励/课程/评估曲线 |
| `Hole/calibrate_low_poses.py` | 低姿态标定：扫描 20～40 mm 板底，拟合前后腿标定角与脊柱俯仰 |
| `Hole/probe_ik_accuracy.py` | 逆运动学探针：检查足端轨迹到关节角的数值一致性 |
| `Hole/verify_low_pose_physics.py` | 低姿态物理可行性（关节范围/力矩/自碰撞）检查 |
| `Hole/verify_head_exclusion.py` | 头颈参考与碰撞排除范围检查 |

诊断产物统一放在 `logs/diagnostics/SQuRo_Hole/<主题>_<日期>/`，路径常量在 `scripts/_diagnostics.py`；不要写到仓库根目录。

## 6. 验收命令

```powershell
uv run python -B -m mjlab.scripts.Hole.verify_hole_obstacle_curriculum   # 课程/考核协议（含退档/最终档）
uv run python -B -m mjlab.scripts.Hole.verify_hole_collision            # 单板几何/碰撞/检查点状态
uv run python -B -m mjlab.scripts.Hole.verify_hole_rebuild_timing       # 3000 轮重建/首回合过滤
uv run python -B -m mjlab.scripts.Hole.verify_hole_corridor_commands    # 阶段边界/命令/走廊
uv run python -B -m mjlab.scripts.Hole.verify_hole_command_reset        # 复位与查表边界
uv run python -B -m mjlab.scripts.Hole.verify_hole_baseline             # 参考表/课程/观测维度
uv run python -B -m mjlab.scripts.Backup.verify_backup_stage_rewards    # 跨任务回归 88 项
```

全部入口应零失败退出；`verify_hole_obstacle_curriculum` 末尾打印“验收通过”，`Backup` 脚本打印“88 项 OK”。
