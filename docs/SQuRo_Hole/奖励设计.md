# SQuRo_Hole 奖励设计

12 个奖励/惩罚项，全部在 `mdp/rewards.py` 实现、在 `SQuRo_Hole_env_cfg.py` 注册。**所有 `cfg.weight` 固定为 1.0**，有效权重/σ 由 `mdp/curriculums.py` 的 `_CURVES` 统一管理（经 `get_curriculum_value(env, name)` 按 `env.common_step_counter` 查询）。改奖励只改 `_CURVES` 或公式，不要改 env_cfg 的 weight，否则破坏唯一来源约定。

## 1. 通用约定

- 正奖励：`r = exp(-σ·误差²) × weight`；惩罚：`p = (exp(-σ·超限量²) - 1) × weight ≤ 0`（接触/走廊）。
- `_CURVES` 每个键是 4 个阶段锚点值（iter 0/1000/2000/3000，取 ≤ 当前 iter 的最后一个锚点，段内保持不变）；唯一例外：`offset_corridor` 在 2000～3000 轮线性收紧。
- 进入阶段 4（≥3000 iter）后的值即最终训练值。
- 奖励键与函数名一一对应：`compute_*_reward` 为正，`compute_*_penalty` 为负；日志键 `Episode_Reward/<key>` 由 manager 生成。

## 2. 奖励项（7 项）

| 键 | 函数 | 公式（逐环境） | 说明 |
| --- | --- | --- | --- |
| `mimic_pos` | `compute_mimic_pos_reward` | `[(exp(-σ_leg·MSE_leg)+exp(-σ_spn·MSE_spn)+exp(-σ_neck·MSE_neck))/2]×w` | 关节位置模仿；脊柱误差按 `SPN_AXIS_SCALE=(1.5,0.7,1.5,0.7)` 逐轴缩放 |
| `mimic_vel` | `compute_mimic_vel_reward` | 同上，误差换成关节速度 | 关节速度模仿 |
| `vel` | `compute_vel_reward` | `exp(-σ_vel·(v_cmd−v_x)²)×w`；若 `|v_cmd|>0.01` 且 `|v_x|<0.01` 则取 `-1` | X 线速度跟踪；静止未起步重罚；日志 `Data/act_vel_x`、`Data/cmd_vel_x` |
| `height` | `compute_height_reward` | `[0.5·exp(-σ_h·e_F²)+0.5·exp(-σ_h·e_H²)]×w`，`e=躯干高度−命令高度` | 前后躯干高度跟踪；日志 `Data/error_height_F/H` |
| `yaw` | `compute_yaw_reward` | `exp(-σ_yaw·yaw_err²)×w`，`yaw_err` 由前后躯干物理偏航的圆均值求得 | 抑制整体偏航 |
| `roll` | `compute_roll_reward` | `exp(-σ_roll·roll_err²)×w`；双高用 `sigma_roll_high`，单低用 `sigma_roll_low` | 前高后低时只约束前段；前低后高时只约束后段；双低模式误差恒为 0（不区分滚转，恒得满分） |
| `foot` | `compute_foot_reward` | 双高模式（Mode 0）才触发：4 只脚 `exp(-σ_foot·(z_foot−target)²)` 取均值×w；`target=0.01×命令高度/BASE_HEIGHT` | 抬脚高度；非 Mode 0 返回 0 |

## 3. 惩罚项（5 项，均 ≤0）

| 键 | 函数 | 公式（逐环境） | 说明 |
| --- | --- | --- | --- |
| `corridor` | `compute_corridor_penalty` | `mean(exp(-σ_c·excess²)−1)×w`，`excess=max(0, 躯干表面最高点 − (命令高度+offset_corridor))` | 全位置走廊；阶段 1/2 权重 0，阶段 3 起打开；offset 在 2000～3000 轮从 30 mm 收紧到 25 mm |
| `contact` | `compute_contact_penalty` | 躯干中心 X 位于 `[x1−5mm, x2+5mm]` 时生效：`mean(exp(-σ_e·excess²)−1)×w`，`excess=max(0, 表面最高点 − (实际板底−2.5mm))` | 虚拟碰撞；前后余量由 `VIRTUAL_CONTACT_X_MARGIN=0.005` 管理；板体不存在或该段中心 X 不在扩展区间返回 0；阶段 1～3 权重 0，阶段 4 起 5 |
| `leg_stop` | `compute_leg_stop_penalty` | Mode 2（前高后低）才触发：`−sum(clamp(0.5−|dq_front|,0))×w` | 防止前腿在低板前“停住” |
| `leg_motion` | `compute_leg_motion_penalty` | 仅单低组合（`front_low ^ hind_low`）：`−strength·mean(dq_low²)×w`，`strength=get_low_height_factor(min(h_F,h_H))` | 抑制低侧腿摆动；双高/双低为 0 |
| `action_L2` | `compute_action_L2_penalty` | `−Σ(a_t−a_{t−1})²×w` | 动作平滑 |

## 6. 调参与验证提示

- 模仿项占主导（阶段 4 权重合计约 15+），改变 `weight_vel`/`weight_height` 时先看 `Episode_Reward/*` 与 `Metrics/success_rate` 的响应。
- `contact` 只在阶段 4 生效，中心 X 判定区间在真实板前后各扩展 5 mm；真实板尺寸、高度位置表与穿板考核范围不随之扩展。调 σ 会改变“轻微擦板”的容忍度，但训练环境无真实接触，最终能力以独立考核环境为准。
- 走廊项 `offset_corridor` 随阶段从 30 mm 收紧到 25 mm；收紧过快会导致阶段 3 早期成功率骤降。
- `mimic_pos/vel` 的 σ 在阶段 4 下调（10→5），是在模仿精度与探索之间折中；若策略明显偏离参考，优先检查参考表与动作缩放，而不是直接加权重。
- 奖励回归：`verify_hole_attitude_rewards`（8 项）覆盖阶段权重/帧一致性；`Backup.verify_backup_stage_rewards`（88 项）覆盖跨任务课程曲线。
